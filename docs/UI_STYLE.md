# 夜行書店：UI 與素材規範

## 設計判讀

以概念圖為準的敘事遊戲介面：午夜雨巷與暖燈書店，日系插畫、舊書頁、細金屬線框。不是網站行銷頁。design-taste-frontend 只用於標題頁的層級、圖片對比與響應式檢查；其 SaaS 排版、亮暗雙主題和新生圖規則不適用既有遊戲美術。

構圖變化 4／動態 3／資訊密度 3。穩定場景讓閱讀優先，轉場只交代場景與操作狀態，尊重減少動態偏好。

## Tokens

- 夜幕 `#101722`、面板 `#111a27`、琥珀金 `#d7b681`、紙色 `#f3e7d3`、次要字 `#c4baa9`。
- 全遊戲單一深色主題；信件紙張是世界內物件，非切換頁面主題。
- 標題使用本機繁體宋體／明體，內文同一書卷字系。控制元件用系統無襯線。
- 基準內文 18px、行高 1.9；可切換 21px。實體點擊目標最少 44px。
- 幾何：主要面板 2px 小圓角、細金邊；章節封面與書籤維持直角。
- 對話固定於場景下側；行動選項能在手機正常換行。場景裝飾不搶鍵盤焦點。
- 桌機接近 16:9；手機保留直向操作，記憶場景使用獨立直向圖，內容必要時捲動。

背景由 ChatGPT 依概念圖重畫、移除所有文字與介面，原圖在 `art-staging/ui-generated/`。視窗矮於 780 px（茶席）或 700 px（拼信）、或寬度在 1180 px 以下時，兩個小遊戲改回上下排列（午夜茶席是寬度 ≤1180 px 或高度 <800 px），手與伏案的林澄也不顯示。手部與伏案背影同樣由 ChatGPT 依概念圖畫成去背圖，都不攔截點擊。


拼信的三個版面陷阱（2026-10-07 修正，改動時留意）：

- 手機與窄版的信紙是 `position: sticky`。信紙格加高（滿版用 150 px）只能放在 `min-width: 641px` 以上，否則放大工作區後信紙會蓋住木盒上方的碎片，手指拖曳會落在信紙上而變成捲動。
- 右欄 `.letter-side` 的 `overflow-y: auto` 只在滿版媒體查詢內；手機若把碎片放進捲動容器，拖曳同樣會被當成捲動。
- 滿版的木盒要在 1440×900 視窗裡放下四片碎片與「共鳴之茶」特殊碎片，碎片高 104 px、小圖 44 px；再加高會讓最後一片被木盒下緣切掉。縮放列移到左上角 88 px 後，兩面信的翻面鈕排在 146 px，不要再讓兩者重疊。
## 後續美術交付

六位後續訪客已有各自桌機／手機書店主場景；結局面板依 28 個結局顯示對應的獨立 3:8 書籤插畫，並以章節主場景作底圖。靜蘭、柏言、若音、葉暖、雨航與店主都有情緒立繪 cue，海明保留搜尋與暖笑兩種立繪，成年林澄在終章有平靜與含淚兩張；信紙碎片加入紙纖維、舊紙色與撕邊質感。八種茶罐、茶壺散茶與八種配料已有對應插畫；奉茶時的製茶影片八種茶各一支，另有四支章節配料影片，由林澄的程序式 3D 雙手演出。七夜共二十八張書籤插畫位於 `public/images/bookmarks/`，對照表在 `src/data/bookmarkArt.ts`；一般視覺素材透過 `src/data/assets.ts` 換入。BGM、雨聲與茶具音效目前使用原創程序式音檔，正式錄音仍待製作。

## 本次第一章與茶席

守夜手記用同一套深藍紙框列出已發現的線索，未讀內容不先揭露。校刊室、病房走廊與月台各有桌機橫幅與手機直向背景；故事標記決定場景，浮在場景上的線索標記與對話選項都執行相同 Ink 選項，已查看狀態由當前選項推得，不建立第二份敘事狀態。場景淡化只用於位置改變，減少動態時立即切換；原記憶書架背景留給拼信。

茶席在桌機採左影片、右操作，在手機改為上下排列。影片使用原創程序式 3D 茶器、暖木、深藍與金邊，與既有插畫尚有材質差異。奉茶影片中林澄的雙手穿深藍大衣與米白襯衫袖口，呼應她的立繪；這是 3D 手部演出，不是原規格的日系手繪手部。換段使用各自海報，減少動態時保留同一構圖及全部操作。

## 3D 茶具材質更新

操作茶席使用共用 3D 模型的透明預渲染素材。八罐茶有不同釉色、木蓋、金屬口沿與弧面紙標；主要器物使用釉面、金屬反射、細微凹凸、內壁與接觸陰影。保持原有木桌、午夜藍、暖金與宋體文字。沙漏、指示、水流和互動命中區仍使用 SVG；不在遊戲載入 WebGL 場景。

完成動畫與注水影片同步使用同一模型，模型與重建方式見 [3D 茶具](TEA_PROPS.md)。
