## 播放

- `TeaCompletion.vue` 以 `TeaFilm` 的 `brew` 片段播放，傳入主導茶種；片段依 WebM／MP4 支援取得完整 Blob 播放，換片或卸載即釋放。影片下方依目前影格標示「取茶・注水・倒茶・奉茶」。
- 湯色：倒茶與奉茶兩段在八種茶完全相同，八支影片共用 `brew-liquor-v1.webp`／`.json` 的半解析度液面遮罩，再以本次泡法的茶湯顏色著色。遮罩在開片時載入；載入失敗時保留影片原本的湯色，不阻止故事。
- 減少動態與影片失敗時顯示該茶最後一格的 `brew-<茶種>-v1-still.webp` 奉茶畫面，並套用同一遮罩；「略過動畫，繼續故事」與 Esc 行為不變。
- 離線：八張奉茶靜態畫面與共用遮罩隨 PWA 預快取；影片與第 0 格海報首次播放時存入瀏覽器快取。舊版單杯完成動畫與六段片段仍在 `public/video/tea/`，不再進入安裝預快取。

已交付六段可播放的程序式 3D 茶席動畫，暖木桌、深藍金邊茶壺、銅水壺與奶白茶杯，固定相機。沒有手部演出與音訊；這是本次實作的美術版本，原規格的日系手繪手部電影感仍屬後續美術升級。

| 片段     | 時長 | 遊戲操作                                                    |
| -------- | ---- | ----------------------------------------------------------- |
| idle     | 4 秒 | 選茶與份量時循環                                            |
| scoop    | 3 秒 | 取茶入壺，結束後進入注水；可略過                            |
| pour     | 4 秒 | 暫停影片，以水量 0–100% 定位時間；按住注水與分次加水皆同步  |
| steep    | 5 秒 | 浸泡時間選擇時循環；30／45／60 秒是配方參數，不要求現實等待 |

每段同時提供 960×540、24 fps 的 H.264 MP4 / VP9 WebM，以及 WebP 海報。六段合計 24 秒。三種茶共用這組動畫，選茶影響配方、計分與劇情，目前沒有各茶種獨立葉形或液色影片。

## 檔案與重建

- 遊戲素材：`public/video/tea/`
- Three.js 可編輯場景：`scripts/tea-film/scene.js`
- 渲染與雙格式輸出：`scripts/render-tea-films.mjs`
- 檢查資料及串接預覽：`output/tea-film/`

```sh
# 需要 ffmpeg、ffprobe、Playwright Chromium；Three.js 只用於製片。
node scripts/render-tea-films.mjs --preview
node scripts/render-tea-films.mjs
```

不在遊戲載入 Three.js。六段影片與海報隨 PWA 預快取；單段很小，播放元件取得完整 Blob 再設為影片來源，以支援離線環境的時間定位，換段或卸載即釋放 URL。選 WebM 或 MP4 依瀏覽器支援；下載失敗可嘗試另一格式，逾時／解碼失敗則顯示海報。

影片有暫停控制。減少動態設定使用海報；非循環片段可略過，不鎖死進度。存檔保存製茶步驟與水量；注水重載還原對應影片位置，取茶／倒茶重載會從該段開頭重播，遊戲結果只在正式遞茶時計算一次。

## 驗證

12 個影片檔皆經 ffprobe 尺寸／幀率／時長核對及 ffmpeg 全片解碼。實際瀏覽器驗證包含影片時間推進、70% 注水重載定位、減少動態、影片無法載入時繼續、桌機與手機版型。仍需實體 Safari／iOS 裝置與人工觀感驗收。
