# 可拖曳茶席

2026-09-22。沿用午夜藍、暖金、月紋茶壺與木質茶桌，將製茶改成可以直接拿取器具的場景。茶席使用 SVG 處理座標與拖曳，器物換成真正 3D 模型渲染的透明 WebP；影片共用同一份模型與材質。

## 玩家流程

1. 從八罐茶中拖一罐到圓墊：桂花烏龍、熟普洱、薄荷茶、茉莉綠茶、蜜香紅茶、洋甘菊、薰衣草伯爵、炭焙焙茶。茶方提供各自溫度、時間與情緒契合。
2. 拖開罐蓋；茶匙拖進罐裡放開，舀起一匙，再拖進茶壺放下。三匙適中，最多五匙。空匙放入茶壺可取回一匙，再放回茶罐。
   注水前可以從另外七罐任選第二種茶放到第二個圓墊，拖開罐蓋後分別從兩罐舀茶；兩種茶葉的總量最多五匙。空茶匙會取回最後加入的一匙，需放回原茶罐。第二罐可以在注水前更換，已放入的第二種茶葉會一併取出。兩種茶的實際匙數會共同決定建議水溫、浸泡時間、茶湯顏色與訪客的契合分數；故事依較多匙的茶種回應，泡茶後會先顯示這杯混茶的組成。第二罐若沒有舀茶，仍視為單茶。
   葉暖章選炭焙焙茶後，可在注水前按「加入一片蘋果乾」；茶壺旁會顯示材料標記，配料可取回，選擇與茶席一同存檔。原味焙茶仍能進入故事，但不會觸發蘋果乾的對話。
   雨航章選薄荷茶後，可在注水前加入或取回檸檬片，並在倒茶入杯前從備好的小壺量取 0–30 毫升淡紅茶。茶湯顏色、評分與雨航的回應依兩種材料的實際選擇改變；原味薄荷仍能進入故事。
   海明章選炭焙焙茶後，可在注水前加入或取回海鹽焦糖；原味焙茶仍可進入故事，海明對燈塔廚房的回應會不同。
3. 調整爐上水溫。把銅水壺移到虛線圈，吸附後向右拖傾倒、向左收水，放開便放回。水量可以分次補到七成；未對準或太滿會灑水。
4. 把壺蓋拖回茶壺，沙漏開始走。三倍遊戲時間，桂花烏龍的 45 秒約等於 15 秒實際等待。點沙漏可暫停／繼續，開選單也會凍結時間；離開分頁後需自行重開沙漏。
5. 提起藍色茶壺停止浸泡，移到杯子上方傾倒。杯中至少 25%（不足一壺時需倒出原水量七成）即可遞給靜蘭。按「將茶遞給她」會打開這杯主導茶種的製茶影片：林澄的雙手取茶、注水、倒茶，再以雙手把茶推到訪客面前，杯中湯色沿用這次泡法；10 秒播放完畢才回傳結果並接回故事。可略過或以 Esc 繼續，減少動態時改為該茶的奉茶畫面與「繼續故事」。見[製茶影片](TEA_FILMS.md)。壺中存量有限，灑掉的茶不能再倒出。

灑水扣分上限 15 分，不會直接判失敗。可以先補水、調整葉量、暫停沙漏，或重新整理茶席換一罐茶。任何品質都能回到故事。尚未倒入杯中時，放回茶壺後可點沙漏繼續浸泡。

鍵盤：Tab 選器具；Enter／空白鍵拿起與放下；方向鍵移動；E 傾倒、Q 收水；Esc 放回。滑鼠另支援滾輪調角度。手機以 Pointer Events 拖曳；只有茶桌阻止捲動，桌外可正常滑動頁面。減少動態設定會關閉蒸氣裝飾，仍保留操作必需的水量回饋。

沙漏外環是浸泡進度：一圈等於茶方秒數的 1.6 倍，金色弧線是茶方秒數 ±4 的最佳時機，進入時發光並響一聲；超過後進度線轉為赭紅。浸泡到兩成後，壺口（倒茶後改在杯口）依茶種飄出桂花、熟普洱的煙縷、薄荷葉、茉莉、蜜香光點、洋甘菊、薰衣草或炭焙火星；兩種茶會交替出現。蒸氣濃淡隨爐上水溫改變。減少動態時關閉粒子、脈動與漣漪動畫，但保留時機環。傾斜注水時有注水聲。

同一張茶席也是[午夜茶席](TEA_HOUSE.md)的獨立製茶模式。

## 程式分工

- `TeaTable.vue`：指標捕捉、鍵盤、吸附、拖曳、逐格流量、沙漏與時機環、茶香粒子、注水聲、操作提示與存檔節奏。故事與午夜茶席共用；父層持有 draft。
- `useTeaBrew.ts`：茶席與側欄共用的衍生狀態。
- `TeaBrewingScene.vue`：故事側欄、章節配料、製茶影片與自動存檔；遞茶後把這杯記進午夜茶席的茶譜。
- `TeaCompletion.vue` / `TeaFilm.vue`：播放主導茶種的製茶影片與液面遮罩，單次播放、略過與結束事件共用一次性回傳。
- `TeaCompletion.vue`：奉茶完成演出，單次播放、略過與結束事件共用一次性回傳，避免重複推進劇情。
- `TeaObject.vue`：依茶種與狀態切換 3D 器物素材；載入失敗時使用原 SVG 備援。沙漏仍為可逐格更新的 SVG。
- `teaPropAssets.json`：渲染輸出的圖像範圍與壺嘴投影；接水判斷直接使用這份座標。
- `teaInteraction.ts`：桌機／手機器物位置、壺嘴旋轉、接水範圍與流量守恆。依水壺／茶壺形狀使用不同對準位置，16–75 度都能落在容器開口。
- `teaScoring.ts`：五項計分、有上限的灑水代價、兩種茶葉按實際匙數加權，以及葉暖蘋果焙茶、雨航薄荷檸檬紅茶、海明海鹽焦糖焙茶的專屬情緒契合分數。
- `catalog.ts`：八種茶的資料；新增茶由資料驅動畫面。

每次放下、暫停與操作中的每秒保存 draft。舊 draft 的新增欄位使用 schema 預設值；第一夜目前 Ink 版本為 `jinglan-chapter-4`，保留 `jinglan-chapter-1.json`、`jinglan-chapter-2.json`、`jinglan-chapter-3.json` 及原型故事，舊位置只套回各自的原編譯檔。

## 邊界

沒有自由 3D 攝影機、手部骨架或真正流體模擬。注水前可更換茶罐；雨航的淡紅茶仍以定量從小壺混入已泡好的茶湯。配料目前使用茶席上的 SVG 材料標記；製茶影片依茶種不同，但仍未按配料改變。手機觸控以 Chromium 裝置模擬及 CDP 真實 touch 事件驗證，仍需 iOS Safari 實機手感測試。
