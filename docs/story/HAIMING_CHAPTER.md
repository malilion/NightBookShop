# 第六夜：顧海明〈熄燈以前，請記得海〉

故事原稿是 `story/chapters/ch06_haiming.ink`，新版獨立編譯為 `haiming-chapter-18`，舊版 `-1` 至 `-17` Ink JSON 保留供原有存檔讀取，完成雨航章後解鎖。雨航的首次結局會改變海明抵達時的對話；若他把信寄往七年後，第六夜會先與雨航短暫重逢，玩家可問第一箱書的起點，或提醒他可以調整做法。他會自己帶走寫有下個月日期的信，兩條對話都接上海明的來訪。海明的記憶退化不是書店魔法能治癒的狀況；書店只讓他和玩家看見回憶，原句與遺忘都會留在故事裡。

開場除原有兩項外，可問顧川照抄父親說錯潮時的那幾頁、請海明像交接值班一樣報今晚的霧，或不問日期、改問早餐吃了什麼。夏日來訪之後，海明會在書店裡再次認不出自己身在何處：林澄可以指著寫有店名的紙再說一次、順著他說今晚的燈有人守著，或告訴他剛才已問過。前兩種讓他重新找到座標；第三種不阻斷任何結局，但他會在白色房間說出最怕別人提醒他忘了時的表情。這些回應分別出現在拼信前與四種後記中。

拼紙船前，若有雨航的首次結局，可以問海明這封信要自己交還是請人送；雨航四種結局各讓海明做出不同的回答，四種後記也分別記下信最後是怎麼交出去的。沒有前夜結局時不出現。

海明翻開日誌時哼出四個音。若已有若音的首次結局，走進暴風夜燈塔以前可以告訴他，前幾晚有位小提琴手正在寫這四個音；若音四種結局各讓海明回答她後來有沒有接上最後一個音，四種後記各留一句痕跡。若有靜蘭的首次結局，也可告訴他第一晚的老師年輕時在校刊室聽過這段旋律；海明不記得從哪裡學來，靜蘭四種結局各帶出他對自己這封信的不同想法，同樣回響在四種後記。

拼紙船後、四種結局選項旁另有兩個可略過的追問。保留原句時，可請海明把「不知道怎麼回到你身邊」念出來：讓他自己念，斷了一次後從頭念完；或由林澄照著停頓念給他聽。也可問他明天醒來要怎麼記得今晚：在日誌這頁折角，或在住址卡背面寫下「今晚寫了信給小川。是真的。」兩者都在四種後記留下痕跡。

熟普洱讓海明坐穩，問妳想聽海難的哪一種：可以請他從風向慢慢說，救援紀錄的燈號會接上他說過的風，〈替記憶留一盞燈〉後記的錄音也從風向開始；也可以問他通常講到哪裡就停，他在救援圖上會把手指移到醫院的號碼，〈燈仍然在這裡〉後記裡他對顧川說完「然後我才去醫院」。薄荷讓他清醒後急著查日期：可以陪他把今天的日期寫在杯墊上，迷路時杯墊仍在他手邊，〈讓紙船出海〉後記裡他又寫下海邊那天和顧川的名字；也可以告訴他說錯日期也沒關係，迷路時他不再先道歉，〈完美的守塔人〉後記裡他說那些說錯的日期比較像他。焙茶路線不出現這些段落。

## 守燈與紙船

開場可觀察兒子寫的姓名住址卡、多種筆跡的航海日誌與擦得乾淨的壞煤油燈。契合且到位的茶讓海明記起顧川替他擺的兩個杯墊；合適的茶讓他自己翻日誌；普通的茶可請他指出要保留的原句，或等他選好頁碼；失衡的茶揭露他把茶溫也當成記憶測驗。四種回應都保留他選擇要讀哪一頁的權利。泡茶後守燈三次：強光讓故事變成英雄傳記，暗光讓細節消失，柔光保留兩種說法。四段記憶依序是暴風夜救船與兒子出生、夏日風箏、最後一次值班及沒有海的白色房間；每段各有三件物件可獨立查看，也可先離開。

四段記憶加入海巡與醫院電話、未搭上的渡船、風箏背面的畫、可暫停的修燈工作、婚禮前的換班與船班，以及住址卡上的求助方式。每件物件都讓海明區分親眼所見、後來聽說與自己不能確定的部分；探索三件後會有對應回應，提前離開時不會替未看的部分補出事實。查看潮汐圖時，林澄會依雨航四種首次結局想起不同的行動或留白；收起紙船角後，可選擇問海明如何把曾能搭上早班船的事寫給顧川。若追問，他會在拼信前留下自己曾有選擇的原句，不把往後的風暴當成替先前決定開脫的理由。拼信前，他也可先說出今天想留下的其他原句；玩家可先排日期，他仍能要求保留重複與猶豫。

缺頁折成紙船，藏在煤油燈裡。四片拼回後，玩家能保留海明重複、停頓和矛盾的原句，或修成流暢的英雄敘述。原句完整且守燈平衡時可與顧川共讀；其他選擇分別留下聲音航海誌、在海邊親口說一部分，或只寄英雄傳記。四結局各有後記。第六夜末的燈塔照片與六封信痕跡引出店主，指出林澄童年曾請書店保管自己的故事；紙背的路線與中心仍留給終章的玩家逐張比對。

守燈、拼頁和閱讀選擇即時存於本機；結局留下獨立章節快照及收藏。茶方「海明的海鹽焦糖焙茶」於完成後出現。茶席選炭焙焙茶後，可在注水前加入或取回海鹽焦糖，選擇存入草稿並改變海明的回應與契合分數。
