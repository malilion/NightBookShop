# 第六夜：顧海明〈熄燈以前，請記得海〉

故事原稿是 `story/chapters/ch06_haiming.ink`，新版獨立編譯為 `haiming-chapter-9`，舊版 `-1` 至 `-8` Ink JSON 保留供原有存檔讀取，完成雨航章後解鎖。雨航的首次結局會改變海明抵達時的對話；若他把信寄往七年後，第六夜會先與雨航短暫重逢，玩家可問第一箱書的起點，或提醒他可以調整做法。他會自己帶走寫有下個月日期的信，兩條對話都接上海明的來訪。海明的記憶退化不是書店魔法能治癒的狀況；書店只讓他和玩家看見回憶，原句與遺忘都會留在故事裡。

## 守燈與紙船

開場可觀察兒子寫的姓名住址卡、多種筆跡的航海日誌與擦得乾淨的壞煤油燈。契合且到位的茶讓海明記起顧川替他擺的兩個杯墊；合適的茶讓他自己翻日誌；普通的茶可請他指出要保留的原句，或等他選好頁碼；失衡的茶揭露他把茶溫也當成記憶測驗。四種回應都保留他選擇要讀哪一頁的權利。泡茶後守燈三次：強光讓故事變成英雄傳記，暗光讓細節消失，柔光保留兩種說法。四段記憶依序是暴風夜救船與兒子出生、夏日風箏、最後一次值班及沒有海的白色房間；每段各有三件物件可獨立查看，也可先離開。雨航先前若將藍色信送往過去，海明查看潮汐圖時會有不同回應。

四段記憶加入海巡與醫院電話、未搭上的渡船、風箏背面的畫、可暫停的修燈工作、婚禮前的換班與船班，以及住址卡上的求助方式。每件物件都讓海明區分親眼所見、後來聽說與自己不能確定的部分；探索三件後會有對應回應，提前離開時不會替未看的部分補出事實。拼信前，他可先說出今天想留下的原句；玩家也可先排日期，他仍能要求保留重複與猶豫。

缺頁折成紙船，藏在煤油燈裡。四片拼回後，玩家能保留海明重複、停頓和矛盾的原句，或修成流暢的英雄敘述。原句完整且守燈平衡時可與顧川共讀；其他選擇分別留下聲音航海誌、在海邊親口說一部分，或只寄英雄傳記。四結局各有後記。第六夜末的燈塔照片與六封信痕跡引出店主，指出林澄童年曾請書店保管自己的故事。

守燈、拼頁和閱讀選擇即時存於本機；結局留下獨立章節快照及收藏。茶方「海明的海鹽焦糖焙茶」於完成後出現。茶席選炭焙焙茶後，可在注水前加入或取回海鹽焦糖，選擇存入草稿並改變海明的回應與契合分數。
