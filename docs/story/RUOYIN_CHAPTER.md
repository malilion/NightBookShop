# 若音第三夜：在最後一個音符之後

完成柏言第二夜後，從章節選單或第二夜結局進入。原稿位於 `story/chapters/ch03_ruoyin.ink`，編譯產物為 `public/story/compiled/ruoyin-chapter-11.json`。前夜首次結局會改變若音抵達時的對話；宴會廳探索企業節目單時，柏言的回診、離職、交接或繼續加班四種結局也會帶出不同的林澄反應，若音則說明一次被聽見不等於往後每場都得替人撐到底。舊版 `-1` 至 `-10` 存檔繼續讀取各自保留的編譯版本。

開場可逐一詢問 PRD 列出的觀察：舊傷、季晴留字的票根、收藏了每一場卻從不買票的演出頁面、琴盒上一年一百多場的商演標籤，以及樂譜最後從未落筆的一小節；也可直接先泡茶。這些回應會在決定最後一小節時，以及只為一個人、寄往有光的舞台、另一種樂章與掌聲的回音四種後記中回響，略過則不出現。

## 可玩流程

1. 觀察斷弦、舊比賽票與左手傷勢；薰衣草伯爵茶在空教室解鎖她第一次真心盼著再演奏的童年回憶與手記線索。茶泡得契合又到位時，她另想起與母親在公車上哼錯音也沒有被評分；合適的茶使她願意停下；普通的茶可追問最怕錯過什麼，或先陪她聽；失衡的茶揭露她連休息都像等評分。任何品質都可繼續四音互動與信。桂花烏龍讓她念起音樂院的名次：可以問走廊窗外那棵樹，讓她想起考試週飄進琴房的桂花，這會在後台與〈寄往有光的舞台〉後記回來；也可以陪她把名單念完，聽她說出自己的「第七名」，這會在後台與〈掌聲的回音〉後記回來。濃紅茶讓她寫下沒有一行提到手的復出計畫：可以問她寫字時會不會痛，她會在後台補上「先問醫師」，〈只為一個人〉後記的練習表第一欄改成手的狀況；也可以陪她寫完、只在每行後留空格，她在後台填下第一格，〈掌聲的回音〉後記裡卻把空格全塗成練習時數。薰衣草路線不出現這些段落。
2. 茶杯邊聽四個音並按順序回應。玩家可重聽、查看文字提示、重試，或帶著不完整的旋律繼續。音序可中途存檔。
3. 走過雨中的空教室、比賽後台、散場的宴會廳和想像中的大舞台；每處可獨立查看三件物件，也可先離開。離開時的收束會區分已查證和未看見的線索，並讓玩家選擇如何向若音追問童年演奏、與季晴的爭吵、婚禮後的三分鐘或她對大舞台仍有的心願。三片信紙的正面寫給季晴，背面寫給十歲的若音。
4. 兩面各自排列並保存在存檔中。正面完成可繼續故事；兩面都拼好、聽出四音，且最後一小節呼應已聽見的故事，才可選擇「只為一個人演奏」。
5. 拼信後可再聽若音談童年四音的停頓、新旋律的聽眾，以及手累時能否留下休止符；若先前略過相關記憶物件，她會在此刻親自說出自己的想法，不假裝玩家曾看過。三段對話均可略過，進度可重載。
6. 替最後一小節選擇回到開頭、加入新旋律或留下休止符。三者分別呼應童年雨聲、宴會廳聽眾或手傷與休息；四條結局各有後記與收藏。

第三夜末，黑貓帶回員工手冊第一頁：「店員也必須留下自己的故事，才能在黎明以前離開。」

## 目前邊界

童年教室、比賽後台、散場宴會廳與沒有盡頭的舞台均有桌機／手機專屬背景；書店對話已有若音透明立繪。四音回應使用 Web Audio 合成音及文字提示；尚未錄製小提琴演奏。章節目標時長尚未達到規劃的 40–50 分鐘。
