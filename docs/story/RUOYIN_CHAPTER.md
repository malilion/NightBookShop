# 若音第三夜：在最後一個音符之後

完成柏言第二夜後，從章節選單或第二夜結局進入。原稿位於 `story/chapters/ch03_ruoyin.ink`，編譯產物為 `public/story/compiled/ruoyin-chapter-4.json`。前夜首次結局會改變若音抵達時的對話；柏言繼續加班的結局亦會在宴會廳的節目單探索中引出另一段反應。舊版存檔繼續讀取各自保留的編譯版本。

## 可玩流程

1. 觀察斷弦、舊比賽票與左手傷勢；薰衣草伯爵茶在空教室解鎖她第一次真心盼著再演奏的童年回憶與手記線索。其他茶仍可探索場景與完成信。
2. 茶杯邊聽四個音並按順序回應。玩家可重聽、查看文字提示、重試，或帶著不完整的旋律繼續。音序可中途存檔。
3. 走過雨中的空教室、比賽後台、散場的宴會廳和想像中的大舞台；每處可獨立查看三件物件，也可先離開。三片信紙的正面寫給季晴，背面寫給十歲的若音。
4. 兩面各自排列並保存在存檔中。正面完成可繼續故事；兩面都拼好、聽出四音，且最後一小節呼應先前聽見的故事，才可選擇「只為一個人演奏」。
5. 替最後一小節選擇回到開頭、加入新旋律或留下休止符。三者分別呼應童年雨聲、宴會廳聽眾或手傷與休息；四條結局各有後記與收藏。

第三夜末，黑貓帶回員工手冊第一頁：「店員也必須留下自己的故事，才能在黎明以前離開。」

## 目前邊界

童年教室、比賽後台、散場宴會廳與沒有盡頭的舞台均有桌機／手機專屬背景；書店對話已有若音透明立繪。四音回應使用 Web Audio 合成音及文字提示；尚未錄製小提琴演奏。章節目標時長尚未達到規劃的 40–50 分鐘。
