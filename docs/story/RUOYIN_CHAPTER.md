# 若音第三夜：在最後一個音符之後

完成柏言第二夜後，從章節選單或第二夜結局進入。原稿位於 `story/chapters/ch03_ruoyin.ink`，編譯產物為 `public/story/compiled/ruoyin-chapter-23.json`（擴寫篇幅，見下段；舊版 `-22` 以前保留供存檔讀取）。前夜首次結局會改變若音抵達時的對話；宴會廳探索企業節目單時，柏言的回診、離職、交接或繼續加班四種結局也會帶出不同的林澄反應，若音則說明一次被聽見不等於往後每場都得替人撐到底。舊版 `-1` 至 `-11` 存檔繼續讀取各自保留的編譯版本。

`ruoyin-chapter-23` 擴寫篇幅，讓首選路線（薰衣草茶、小遊戲完成）由約 7,000 字、32.8 分鐘增至約 9,700 字、40.5 分鐘（`tests/chapterLength.ts` 的快讀模型）。新增六個可略過的觀察或追問，都放在各選單第一項、看完回到原選單：開場問她為何握著琴弓卻不開琴盒（`asked_bow`，在〈只為一個人演奏〉時她先打開琴盒才拿弓）、空教室窗台上記滿練琴日期的松香盒（`read_child_rosin`）、後台鏡邊季晴畫了星星的出場順序表（`read_backstage_order`）、宴會廳清潔人員自己打開的摺椅（`read_banquet_chair`）、大舞台掌聲空隙裡的雨聲（`heard_grand_gap`），以及拼信後問她這些年在別人的曲子裡偷偷留下的半拍（`score_own`）。另在四個記憶場景的開場與離場、茶杯四音、拼信回應與最後一小節前補上可觀察細節與若音的短句（舊外套、季晴調音、主持人的手勢、看不見台下的燈），以及林澄的幾處小反應。未新增角色與設定。

選了「先讓她把那句傷人的話原樣念完」或「問她是否仍想站上真正的大舞台」的人，四種後記各多一句：季晴那句「有沒有吃飯」在她心裡被說完，以及想上台的自己不再被說成錯的。這些選項都不是選單的第一項，首選路線不會經過，篇幅不變。

童年雨天的記憶進場時，兩種非首選的茶也各多一句：桂花烏龍讓她想起放學公車上還沒有人打分數的時候；濃紅茶讓她像要上台般坐直，看見十歲的自己聽雨才放下肩膀。

大舞台的記憶進場時，兩種非首選的茶也各多一句：桂花烏龍讓她說名次表上永遠還有下一個名字，台上的燈卻只照一個人；濃紅茶讓她挺直了背，左手卻先縮了一下。

婚宴廳的記憶進場時，兩種非首選的茶各多一句：桂花烏龍讓她說婚禮沒有名次、只要準時結束，濃紅茶讓她說那晚手已在痛、計畫表上卻沒寫。這些句子只在非首選的茶出現，不改變篇幅測試量的首選路線。

拼信開始前也會依當晚的茶多一句（`tea_before_letter`），讓茶在中後段留下回響：薰衣草讓她的左手第一次沒有握成拳，桂花烏龍讓她說起花開時練琴比較慢，濃紅茶讓她看著計畫表不再加任何一行。

四種後記的最後都會依當晚泡的茶多一句（`tea_afterword`），三種茶各一句，寫成四種結局都成立的樣子：薰衣草成為琴盒裡讓手慢一點的香氣，桂花讓她在花開時哼起放學公車上的歌，濃紅茶讓她練琴前喝到一半時停下來看看手。

四種結局的收尾各有一個林澄的二選一，回應留在後記：只為一個人拉完後，可遞溫毛巾讓她先暖手，或問她手還好嗎、等她自己說「有一點痠」；寄信給季晴時，可陪她走到門邊的信箱，或讓她明天自己寄掛號；留下交換簿時，可請她先替自己寫第一段，或把簿子立在櫃台留給下一位客人；勸她帶傷參賽之後，可承認自己說得太快，或替她把練習時程抄得工整（介入加深）。

寫最後一小節前，問過若音手累時能不能留下休止符，她會反問林澄有沒有一件小時候很喜歡、後來停下來的事。林澄可以說小時候常在紙角畫月亮、搬家以後就沒再畫，若音請她在譜角畫一個；也可以說想不起來，若音說想不起來也像休止符，撕下畫了休止符的紙角給她。兩種回答在章末找到手冊第一頁時留下林澄的一句，並在四種後記各留下痕跡。沒有談過休止符時不出現。

開場可逐一詢問 PRD 列出的觀察：舊傷、季晴留字的票根、收藏了每一場卻從不買票的演出頁面、琴盒上一年一百多場的商演標籤，以及樂譜最後從未落筆的一小節；也可直接先泡茶。這些回應會在決定最後一小節時，以及只為一個人、寄往有光的舞台、另一種樂章與掌聲的回音四種後記中回響，略過則不出現。

翻開大舞台最後一頁後，林澄會依柏言的首次結局想起他如何處理疲累；接著可問若音手累時有沒有哪一段能交給別人。柏言留下界線或繼續加班時，若音的回答各不相同；其他情況她會在譜上畫一個讓鋼琴先走的記號。這個記號留在〈只為一個人演奏〉的後記，在〈掌聲的回音〉後記裡則被她自己擦掉。可略過；第一次從第三夜開始、沒有前夜結局時仍會看到這個問題。

寫最後一小節前，若已有靜蘭的首次結局，可告訴若音第一晚有位老師也聽過這四個音、最後一個音沒有落下。靜蘭四種結局各讓若音給出不同回答：先寫給十歲的自己、先問想聽的人、讓最後一個音晚一點落下，或在林澄替靜蘭封口時請她讓自己寫。四種後記各留下一句痕跡。這是第一個非相鄰的前夜回應：`gameStore` 現在會把更早各夜的首次結局傳給每一章，Ink 宣告 `ending_<訪客>` 變數才會讀到。

## 可玩流程

1. 觀察斷弦、舊比賽票與左手傷勢；薰衣草伯爵茶在空教室解鎖她第一次真心盼著再演奏的童年回憶與手記線索。茶泡得契合又到位時，她另想起與母親在公車上哼錯音也沒有被評分；合適的茶使她願意停下；普通的茶可追問最怕錯過什麼，或先陪她聽；失衡的茶揭露她連休息都像等評分。任何品質都可繼續四音互動與信。桂花烏龍讓她念起音樂院的名次：可以問走廊窗外那棵樹，讓她想起考試週飄進琴房的桂花，這會在後台與〈寄往有光的舞台〉後記回來；也可以陪她把名單念完，聽她說出自己的「第七名」，這會在後台與〈掌聲的回音〉後記回來。濃紅茶讓她寫下沒有一行提到手的復出計畫：可以問她寫字時會不會痛，她會在後台補上「先問醫師」，〈只為一個人演奏〉後記的練習表第一欄改成手的狀況；也可以陪她寫完、只在每行後留空格，她在後台填下第一格，〈掌聲的回音〉後記裡卻把空格全塗成練習時數。薰衣草路線不出現這些段落。
2. 茶杯邊聽四個音並按順序回應。玩家可重聽、查看文字提示、重試，或帶著不完整的旋律繼續。音序可中途存檔。
3. 走過雨中的空教室、比賽後台、散場的宴會廳和想像中的大舞台；每處可獨立查看三件物件，也可先離開。離開時的收束會區分已查證和未看見的線索，並讓玩家選擇如何向若音追問童年演奏、與季晴的爭吵、婚禮後的三分鐘或她對大舞台仍有的心願。三片信紙的正面寫給季晴，背面寫給十歲的若音。
4. 兩面各自排列並保存在存檔中。正面完成可繼續故事；兩面都拼好、聽出四音，且最後一小節呼應已聽見的故事，才可選擇「只為一個人演奏」。
5. 拼信後可再聽若音談童年四音的停頓、新旋律的聽眾，以及手累時能否留下休止符；若先前略過相關記憶物件，她會在此刻親自說出自己的想法，不假裝玩家曾看過。三段對話均可略過，進度可重載。
6. 替最後一小節選擇回到開頭、加入新旋律或留下休止符。三者分別呼應童年雨聲、宴會廳聽眾或手傷與休息；四條結局各有後記與收藏。

第三夜末，黑貓帶回員工手冊第一頁：「店員也必須留下自己的故事，才能在黎明以前離開。」

## 目前邊界

童年教室、比賽後台、散場宴會廳與沒有盡頭的舞台均有桌機／手機專屬背景；書店對話已有若音透明立繪。四音回應使用 Web Audio 合成音及文字提示；尚未錄製小提琴演奏。首選路線在快讀模型下約 40.5 分鐘，尚未經真人計時。
