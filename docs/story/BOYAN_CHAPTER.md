# 柏言第二夜：明日之前，請讓我停一下

第一夜完成後，從章節選單或第一夜結局進入第二夜。Ink 原稿是 `story/chapters/ch02_boyan.ink`，由 `npm run build:ink` 產生 `public/story/compiled/boyan-chapter-15.json`（舊版 `-14` 以前保留供存檔讀取）。前夜首次結局會改變柏言抵達時的對話，靜蘭被代為決定的結局也會在辦公室觸發一段不同反應。進門後可逐項看識別證、停在 23:47 的手錶、袖口沒喝完的咖啡、公事包裡自己買的胃藥與三張日期不同的辭職信草稿，以及翻面仍會先伸手去碰的手機；每一項都能略過，直接燒水。看過藥的人，在候診區會分清自己買的藥和診間的藥袋；看過手機的人，在列車上會讓手也停一下。第一夜及柏言舊版 `-1` 至 `-12` 存檔仍讀取各自保留的編譯檔。

拼信後問過柏言今晚離開書店要去哪裡，他會反問林澄幾點下班。林澄可以老實說門在天亮前打不開、也沒人知道她在這裡，柏言說這種班他上了七年，在紙巾上寫「天亮後，先讓一個人知道妳在哪裡」；也可以說自己還好、不累，柏言聽出那是他在公司說了七年的話，只說「哪天不好，也可以說」。兩種回答在四種章末旁白留下林澄的一句，並在四種後記各留下柏言後來的做法。沒有問過他今晚去處時不出現。

## 流程

拼信前，若有靜蘭的首次結局，可以告訴柏言昨晚有位客人的信放了五十年；靜蘭四種結局各讓他決定不同的寄法：先寄一份給自己、先問主管何時方便談、承認身體等不了五十年，或在林澄曾替靜蘭封口時說「這封我自己來」。四種後記分別記下信最後怎麼寄出或仍留在草稿匣。沒有前夜結局時不出現。

拼信後、四種結局選項旁另有三個可略過的追問。讀懂整封信時，可問柏言那一疊「抱歉」要怎麼處理：陪他數出多半是替別人道歉、把「我身體不太好」那句劃掉；或問他哪一句是真心想說的，他撕下一句沒告訴母親自己昏倒的道歉，決定當面說。開場問過手錶時，可看他把停在 23:47 的錶解下、錶面朝上放在信旁。也可問他今晚離開後去哪裡，他把「胸悶不退或頭暈，直接去急診」釘選在備忘錄最上面。三者都在四種後記留下痕跡。

1. 觀察識別證、停在 23:47 的手錶、袖口的冷咖啡、公事包裡的胃藥與三張未寄草稿、翻面的手機。可先倒一杯水，也可直接燒水。
2. 泡茶；洋甘菊可加一小匙蜂蜜，兩者一起才是最貼近他的茶，也會開啟身體警訊與求助的專屬對話。濃紅茶使他重新打開筆電，須再談一輪才能合上；薄荷茶讓他把今晚、明早與需要找人談的事分欄，仍未完全放鬆。茶種、配料與沖泡品質分別影響後續回應：共鳴之茶帶出柏言入職初期下班後逛二手書攤的記憶；合適的茶讓他放慢；普通的茶可再問他最怕哪件事停下來，或先讓他自己想；失衡的茶則暴露他連喝慢都要道歉的習慣。任何品質都可繼續故事。
3. 在凌晨辦公室、候診區與通勤列車各探索三件物件，也可提早離開。列車離開前需由柏言逐則暫停三則工作通知；母親的私人訊息可選擇此刻回覆或留到明天。通知進度可中途讀檔。三段記憶會依序找到四句話：現況、界線、交接、下一步。草稿日期連到林澄主線。
4. 把四句話排成信。拼得不完整仍可繼續；看過三版草稿並排對四格，會增加理解。
5. 由柏言決定先請假就醫、盤點離職、和主管談工作負荷，或繼續做報告。四條路各有後記與獨立收藏。

章節不把辭職當唯一正解。持續胸悶或再次昏厥的情況，劇情會指向醫療協助。結局存入 `chapter-boyan` 首次完成快照，收藏保留在本機。

新版在辦公室分清自願補位、被代為答應與真正能交接的工作；候診區讓柏言看見醫囑、藥袋和未寄的請假訊息；列車把工作通知、母親的訊息與七年前的草稿分開處理。三段記憶各依已探索物件收束，提前離開時不替未讀證據下結論。拼信前可先問柏言最想讓收信者看見的現況，也可先替他排交接；後一條路線仍讓柏言親手把現況移回第一頁。四種結局各補上就醫、財務與支持系統、團隊分工或繼續加班的實際後果。

茶與休息不替代醫療評估；若胸悶再起、呼吸困難或再次昏厥，劇情提醒不能等到明早門診。相關警訊依[衛生福利部國民健康署就醫提醒](https://www.mohw.gov.tw/cp-16-84825-1.html)核對，故事不指定病因。
