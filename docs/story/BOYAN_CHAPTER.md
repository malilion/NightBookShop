# 柏言第二夜：明日之前，請讓我停一下

第一夜完成後，從章節選單或第一夜結局進入第二夜。Ink 原稿是 `story/chapters/ch02_boyan.ink`，由 `npm run build:ink` 產生 `public/story/compiled/boyan-chapter-6.json`。前夜首次結局會改變柏言抵達時的對話，靜蘭被代為決定的結局也會在辦公室觸發一段不同反應；第一夜及柏言舊版存檔仍讀取各自保留的編譯檔。

## 流程

1. 觀察識別證、停在 23:47 的手錶與柏言對工作通知的反應。
2. 泡茶；洋甘菊可加一小匙蜂蜜，兩者一起才是最貼近他的茶，也會開啟身體警訊與求助的專屬對話。其他茶與原味洋甘菊都可繼續故事。
3. 在凌晨辦公室、候診區與通勤列車各探索三件物件，也可提早離開。列車離開前需由柏言逐則暫停三則工作通知；母親的私人訊息可選擇此刻回覆或留到明天。通知進度可中途讀檔。三段記憶會依序找到四句話：現況、界線、交接、下一步。草稿日期連到林澄主線。
4. 把四句話排成信。拼得不完整仍可繼續；看過三版草稿並排對四格，會增加理解。
5. 由柏言決定先請假就醫、盤點離職、和主管談工作負荷，或繼續做報告。四條路各有後記與獨立收藏。

章節不把辭職當唯一正解。持續胸悶或再次昏厥的情況，劇情會指向醫療協助。結局存入 `chapter-boyan` 首次完成快照，收藏保留在本機。

## 目前邊界

辦公室、候診區與列車各使用專屬橫向／直向背景，書店對話已有柏言透明立繪。列車通知已有獨立操作介面，四格信沿用既有拼信操作。工作通知僅能逐則暫停；沒有模擬實際手機系統推播。
