# 靜蘭第一章：月下未寄出的信

靜蘭第一章包含三段記憶、三片信紙、四種結局與各自後記。Ink 原稿是可執行的章節，包含對話、觀察回應及條件分支；第二至六夜與終章另有章節文件。

## 敘事順序

| 段落             | 玩家動作                       | 內容與回收                                                         |
| ---------------- | ------------------------------ | ------------------------------------------------------------------ |
| 序章、來客       | 閱讀手冊，觀察婚戒、票根、信封與白山茶 | 林澄是暫代店員；手冊缺第一頁，黎明前不能離開                       |
| 製茶、傾聽       | 三種茶與製茶選擇               | 桂花烏龍喚起樹下讀詩的記憶，沖泡失手仍可聽見；其他茶改變開口方式         |
| 記憶一：校刊室   | 編輯名單、稿紙改字、獎學金通知 | 靜蘭確實想與岳川同行；取得起筆碎片                                 |
| 記憶二：病房走廊 | 病床、繳費單、公用電話、可選的家人追問 | 父親住院，她選擇留下；可理解家人原先的反對與她自己的決定；取得原因碎片，容許中途歇息 |
| 記憶三：月台     | 長椅、班次與進站戳記、詩集     | 她曾抵達，只是錯過列車；取得末句碎片                               |
| 書店、拼信       | 聽後來的婚姻，辨認兩種墨跡；拼好後可追問或直接交還 | 後來的幸福真實存在；「請不要等我」與多年後「請原諒我」分屬不同時期，靜蘭不替岳川說出未留下的答案 |
| 決定、離開       | 讓靜蘭自己選擇，或越過她的拒絕 | 四條完整結局，各有可見後果                                         |
| 章末、後記       | 看見舊址、閱讀日後片段         | 門牌伏筆與缺頁手冊保留；後記明示時間，不賦予林澄預知能力           |

## 四種結局

| 結局         | 條件                                                                | 結果                                       |
| ------------ | ------------------------------------------------------------------- | ------------------------------------------ |
| 月光抵達之處 | understanding ≥ 4、讀懂完整原信、intervention = 0，選擇陪她寫給自己 | 她留下兩封信，七天後聯絡老同學             |
| 遲來的收件人 | 詢問寄信意願，她同意先寄詢問短箋                                    | 女兒十四天後回覆願意收信，靜蘭自行寄出原信 |
| 再等一個夜晚 | 交還信件，或在寄信詢問中收回                                        | 星期日的日常繼續，未決定不等於失敗         |
| 替她決定的人 | 選擇代寄，聽見「等等」後仍封口                                      | 回信不能抵銷越界，書籤留下裂痕             |

代寄之前可以停筆，撤回該次 intervention 增量；其他先前強加的判斷不會被自動洗去。拼信允許留白，茶泡壞不會卡關。可選觀察是理解與角色細節，三片必要信紙則隨三段記憶必定取得。

## 守住的設定

- 靜蘭七十四歲，往事在五十年前；岳川在本章之前已去世。
- 她當年對岳川的感情、後來對先生的愛都是真的，不將後來的婚姻寫成替代品。可詢問先生種下、夾在購物清單裡的白山茶；靜蘭會親手將它與藍信分開擺放。
- 記憶不能證明岳川未曾留下的念頭；他沒有寫下「原諒」，玩家不能代他發言。
- 林澄不能替訪客完成決定，章末也尚未得知如何離開書店。
- 原稿約一萬個漢字，包含互斥分支，不能當作單次遊玩字數；35–45 分鐘仍需真人閱讀測量。
