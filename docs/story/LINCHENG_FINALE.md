# 終章：林澄〈黎明以前，留下我的故事〉

終章原稿為 `story/chapters/finale_lincheng.ink`，新版獨立編譯為 `lincheng-chapter-4`，舊版 `-1` 至 `-3` Ink JSON 保留供原有存檔讀取。完成海明章後可從章節選單進入，也可在第六夜結局直接翻開；海明的首次結局會改變林澄進入訪客席前的對話。林澄可以在開場拒絕坐到訪客席；其餘路線由她為自己泡茶開始。

## 六夜地圖與自己的信

六位訪客留下的信封、草稿、樂譜、食譜、郵戳及照片各有一面可查看。六張紙都翻過後，水痕、油漬與摺線組成以夜行書店為中心的地圖，並顯示靜蘭與若音、柏言與靜蘭、葉暖與雨航、雨航與海明之間的連結。探索進度存於本機。

收藏室、童年住處與童年書店各有三件可逐一查看的物件，也可先離開；海明若留下只見功績的英雄傳記，林澄查看信櫃時會把他的原稿與傳記並排。林澄童年曾藏起父親寫的一封信，害怕父母分開，也希望母親搬到安靜安全的地方。父母的決定由大人負責；信確實由孩子藏過，她的害怕也真實存在。她請書店暫存寫給長大後自己的四片信紙。店主沒有替她寫答案，並承認讓她以為無法離開是不妥的。拼頁可留白；完整閱讀並比對六夜地圖，才能選擇帶著記憶在天亮後離開，或自願成為下一任守夜人。其餘選擇讓信留在書架，或拒絕坐下而停在午夜。

四個最終結局各有後記、書籤與獨立章節快照。故事不把「記起來」當成所有人的唯一正確答案，離開與留下都必須是林澄自己的選擇。

## 驗證與限制

Ink 編譯、四結局定向路徑、每節還原、六紙比對與四片信評分已測試。桌面／手機 Chromium 已走通為自己泡茶、九件場景物件、收藏室已讀狀態重載、地圖及拼信中途重載、〈天亮以後〉結局與收藏。其他三種最終結局已從最終選擇前的有效存檔接續驗證結局與收藏，尚未逐條從開場重玩。

終章收藏室、童年住處與童年書店櫃台各有桌機／手機專屬背景，童年住處也納入終章離線素材包。童年林澄與店主仍待獨立角色美術；內容時長未經真人閱讀計時，視覺與演出仍需補齊才達到完整遊戲的目標。
