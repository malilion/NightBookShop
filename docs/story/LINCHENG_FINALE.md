# 終章：林澄〈黎明以前，留下我的故事〉

終章原稿為 `story/chapters/finale_lincheng.ink`，新版獨立編譯為 `lincheng-chapter-12`，舊版 `-1` 至 `-11` Ink JSON 保留供原有存檔讀取。完成海明章後可從章節選單進入，也可在第六夜結局直接翻開；六位訪客的首次結局會分別改變收藏室信櫃的對應一格，海明的結果也會改變林澄進入訪客席前及與店主談話時的內容。林澄可以在開場拒絕坐到訪客席；拒絕後仍可問店主那張椅子會不會留著、去試玻璃門能不能打開、翻看六位訪客的手記，然後改變心意坐下，或再次拒絕走向〈不會天亮的書店〉。試過門與讀過手記會留在該結局與後記：她知道門能開，這次留下不是被關住。其餘路線由她為自己泡茶開始。

店主為童年的保管請求道歉後，林澄可回看自己在六夜裡是否也曾替訪客決定。每夜各有一種這樣的結局：替靜蘭封口、讓柏言先把報告做完、勸若音帶傷參賽、要葉暖一筆不改地照舊、說雨航的信是地址寫錯、把海明的猶豫刪成傳記。只要有任何一夜走到其中之一，就能告訴店主自己也這樣做過，並逐一說出實際發生過的那幾夜；店主不因此要求原諒，〈下一任守夜人〉與〈天亮以後〉的後記會留下她日後的做法。六夜都沒有越界時，改為告訴店主六位訪客都是自己做的決定，要求他同樣讓自己拆信，回響在守夜人與〈留在書架上的信〉後記。兩者都可略過。

## 成為訪客

八種茶各有一段回應：桂花、熟普洱、薄荷、紅茶、洋甘菊、薰衣草與焙茶分別讓林澄想起喝過它的訪客；六夜沒有人選過的茉莉，則讓她發現自己不知道喜歡什麼茶。泡茶品質達 90 分時，她第一次照自己的節奏泡完一杯；低於 50 分時，她想倒掉重泡，才想起這杯不必端給任何人。

為自己泡好茶後，店主坐到林澄這六夜的位置，先問能不能像她觀察客人那樣觀察她；林澄可以拒絕，直接去看六夜的紙。同意時，可逐一聽他說看見的三件事：拇指一直按著徽章、六位客人的杯子都洗好了自己的最後才拿、坐下後第一眼看的是門。離開童年住處前，林澄也可以想想後來從未問過母親那一晚，以及每年只寄一張卡片的父親。這些回應在天亮以後、下一任守夜人與留在書架上的信三種結局的後記中回響，略過則不出現。

## 六夜地圖與自己的信

六位訪客留下的信封、草稿、樂譜、食譜、郵戳及照片各有一面可查看。翻看六張紙並接上五段有根據的人物、地點與旋律關係後，才顯出以夜行書店為中心的地圖。第六夜結尾及終章入座前只顯示未辨明的紙背痕跡；探索進度存於本機。

收藏室、童年住處與童年書店各有三件可逐一查看的物件，也可先離開。查看六格信櫃時，靜蘭、柏言、若音、葉暖、雨航的格子各依本輪首次結局顯示不同痕跡；海明與顧川共讀、留下聲音航海誌、帶紙船去海邊，或只寄英雄傳記，則在第六格留下不同痕跡。若缺少某夜結局快照，該格不憑空宣告後續；已開始的終章以自己的 Ink 存檔保留當時的結果。林澄與店主談話時也依自己當時如何對待海明的故事，說出不同的界線。林澄童年曾藏起父親寫的一封信，害怕父母分開，也希望母親搬到安靜安全的地方。父母的決定由大人負責；信確實由孩子藏過，她的害怕也真實存在。她請書店暫存寫給長大後自己的四片信紙。店主沒有替她寫答案，並承認讓她以為無法離開是不妥的。玩家可追問童年的保管請求為何變成成年後推不開的門；店主須承認那不是守夜的同意，林澄也能要求手冊把兩件事分開記。拼頁可留白；完整閱讀並比對六夜地圖，才能選擇帶著記憶在天亮後離開，或自願成為下一任守夜人。讀信後也可讓信暫留書架；〈不會天亮的書店〉只由開場拒絕坐下、拒絕讀信進入。

四個最終結局各有後記、書籤與獨立章節快照。故事不把「記起來」當成所有人的唯一正確答案，離開與留下都必須是林澄自己的選擇。

共用的章末旁白只回顧六位訪客留下的痕跡，不預設柏言停工、若音完成演奏或海明保留原句等特定結局；海明四種首次結局仍在信櫃與店主對話保留各自的回應。

## 驗證與限制

Ink 編譯、四結局定向路徑、每節還原、六紙比對與四片信評分已測試。桌面／手機 Chromium 已走通為自己泡茶、九件場景物件、收藏室已讀狀態重載、地圖及拼信中途重載、〈天亮以後〉結局與收藏；靜蘭與海明共讀結局的真實章節快照已驗證能改變終章信櫃畫面。前五夜各四種首次結局對應的信櫃文字，以及舊 `-8` Ink 路線，由單元測試核對；其他結果尚未逐一在瀏覽器從開場重玩。林澄其餘三種最終結局已從最終選擇前的有效存檔接續驗證結局與收藏，尚未逐條從開場重玩。

終章收藏室、童年住處與童年書店櫃台各有桌機／手機專屬背景，童年住處也納入終章離線素材包。童年林澄與店主已有獨立角色立繪，於對應敘事段落顯示；內容時長未經真人閱讀計時，表情變化與演出仍需補齊才達到完整遊戲的目標。
