# 第五夜：程雨航〈收件人是我自己〉

故事原稿是 `story/chapters/ch05_yuhang.ink`，新版獨立編譯為 `yuhang-chapter-6`，舊版 `-1` 至 `-5` Ink JSON 保留供原有存檔讀取。完成葉暖章後可從章節選單開始；葉暖的首次結局會改變雨航抵達時的對話。薄荷茶可量取淡紅茶並搭配檸檬；洋甘菊可加蜂蜜，焙茶可加蘋果乾。配料的實際選擇會存入茶席草稿，並改變契合分數與雨航的回應。只有加入蜂蜜的洋甘菊茶會出現妹妹在車站的夢話。

## 路線與信

雨航帶著唯一淋濕的藍色信、停在「明年再開始」的派送簿與木製書店鑰匙圈進門。泡茶後，玩家依郵戳、雨痕與自己的字跡選三個投遞地點。每個線索在四個地址都有對應片段；走對可核對真實記憶，走錯則看見雨航當年可能選擇的另一種生活，仍能繼續。同一地址不能重複選，走到第二站時重載仍會保留路線與片段。老郵局、末班公車、空店面與夜行書店門外各有三件可逐一查看的物件，也可先離開；四片信紙仍按主線取得。拼信前可從妹妹的明信片、雨航親簽的租約，或他目前想如何處理信件切入談話；明信片與租約是否實際查看會改變回應，不阻斷任何結局。四片拼好後可查看逐年重寫的墨跡，再選過去、現在或未來的一枚郵票。葉暖先前若選擇讓晨麥休息一週，雨航在查看老郵局派送簿時會想起那個帶日期的決定。

信不是預言，而是雨航在妹妹離世後每年寫給自己、又不肯寄出的話。完整理解且貼「現在」才能選「今日簽收」；「未來」可留下下個月的明確行動，並在第六夜開場再次與他交談，「過去」可放下共同開店計畫。拒絕簽收會走向「查無此人」。四個結局都有後記，並揭露藍色信上七年後的郵戳刻著書店門牌。

路線、信片和郵票即時寫入本機存檔。第五夜結局有獨立快照與收藏，茶方「雨航的薄荷檸檬紅茶」於完成後出現。茶席選薄荷罐後，可在注水前加入或取回檸檬片，並量取 0–30 毫升淡紅茶；選洋甘菊或焙茶可分別加入蜂蜜或蘋果乾。用量與配料選擇都會存入草稿，改變雨航喝茶時的回應與契合分數。

## 驗證與限制

Ink 編譯、四結局路徑、逐節還原、錯路可繼續、拼信前談話的已查／未查證據分支、信片與舊存檔預設值已測試。桌面／手機 Chromium 已實際走完最佳結局，並重載檢查檸檬片、淡紅茶用量、老郵局物件、投遞路線與郵票；三次錯路另從有效路線存檔驗證不同生活片段、禁止重複站點、第二站重載與回書店。其他三結局已從最終選擇前的有效存檔接續，在桌機／手機瀏覽器核對結局與收藏；尚未逐條從開場重玩。

書店對話已有雨航透明立繪，老郵局、末班公車、空店面與書店門外皆有專屬桌機／手機背景。四段場景已在桌機／手機 Chromium 完整路線核對圖片載入與對話畫面；PRD 的 45–55 分鐘時長尚未真人測量，仍需節奏試玩與擴充。
