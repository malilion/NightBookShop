# 第五夜：程雨航〈收件人是我自己〉

故事原稿是 `story/chapters/ch05_yuhang.ink`，新版獨立編譯為 `yuhang-chapter-25`（擴寫篇幅，見下段），舊版 `-1` 至 `-24` Ink JSON 保留供原有存檔讀取（`-18` 新增走到門口又回來時的不安立繪）。完成葉暖章後可從章節選單開始；葉暖的首次結局會改變雨航抵達時的對話。薄荷茶可量取淡紅茶並搭配檸檬；洋甘菊可加蜂蜜，焙茶可加蘋果乾。配料的實際選擇會存入茶席草稿，並改變契合分數與雨航的回應。只有加入蜂蜜的洋甘菊茶會出現妹妹在車站的夢話。契合且到位的茶另喚起妹妹寫在派送簿背面的提醒；合適的茶讓他坐下；普通的茶可問他自己的住址或先看收件欄；失衡的茶揭露他連杯子也想替人送達。品質分支都能繼續投遞路線。

`yuhang-chapter-25` 擴寫篇幅：固定首選路線（薄荷茶、小遊戲都完成）由 7,259 字、約 33.7 分鐘增為 9,763 字、約 40.8 分鐘（`tests/unit/chapter-length.test.ts` 的快讀模型）。必經段落多了可觀察的細節與林澄的小反應：簽收單上只空著的簽收欄、看林澄燒水時錯把水壺聲當門鈴、老郵局缺角的第三級石階（妹妹等父親下班的位置）、站牌上被雨航用原子筆補正的時刻表、沒有人按下車鈴的末班車與在後照鏡裡問他的司機、空店面的綠格地磚與沒有燈泡的燈座、和家門鑰匙掛在同一圈的空店面鑰匙、門外雨航問書店幾點關門、每一年越寫越工整的信，以及林澄在手冊空白頁停筆。三片信紙取得後各多一句雨航的反應（「沒有她」後面那半句是他自己每天補上的）。拼信前的談話多了他每天交完簿子繞去確認店門還鎖著的自白。

另有五個可略過的追問，都放在原選單第一項、看完回到選單：開場「問他今晚還剩幾戶沒送」（`asked_route_left`，記得門牌後的人何時關燈、走回局裡那段空手的路），老郵局「看看牆角那個被封住的投信口」（`read_post_slot`，妹妹貼著牆聽信落到底），末班車「問他平常都坐在哪個位置」（`asked_bus_seat`，後門旁與妹妹坐的最前排），空店面「問他們第一次來看這間店的那天」（`asked_first_visit`，捲尺與十四步、靠窗的長椅），書店門外問過剩幾戶時「問他今晚剩下的十一戶怎麼辦」（`asked_route_rest`）。回響：〈今日簽收〉後記他在看店面時數到第十四步，〈退回過去〉後記他在海邊郵筒前貼耳聽信落下，〈查無此人〉後記他仍快步走回局裡。

選了「讓他先把派送簿收好」或（普通茶之後）「讓他先看清信的收件欄」的人，四種後記各多一句：他分清父親的紀錄是別人的信，以及不論有沒有簽收，都知道收件欄上的名字是自己的。這些選項都不是選單的第一項，首選路線不會經過，篇幅不變。

開門時問他要不要進來躲雨的人，四種後記也多一句：每逢下雨，他仍會先替信找地方躲。

書店門外的記憶進場時，兩種非首選的茶也各多一句：洋甘菊讓他第一次沒有先看手錶；焙茶讓他握住郵袋背帶，卻沒有轉身。至此四段記憶都有非首選茶的回響。

老郵局的記憶進場時，兩種非首選的茶也各多一句：洋甘菊讓他在缺角的石階前停住很久；焙茶讓他看了一眼手錶，又把手放回口袋。

空店面的記憶進場時，兩種非首選的茶也各多一句：洋甘菊讓他在玻璃前站得比平常久，沒有急著說「明年」；焙茶讓他鞋尖朝著來時的路，人卻沒有動。

末班車的記憶進場時，兩種非首選的茶各多一句：洋甘菊讓他第一次沒有數還有幾站，焙茶讓他經過自己那條街時手停在下車鈴上，卻沒有按。這些句子只在非首選的茶出現，不改變篇幅測試量的首選路線。

拼信開始前也會依當晚的茶多一句（`tea_before_letter`），讓茶在中後段留下回響：薄荷茶喝完他把杯把轉向自己、不朝向門，洋甘菊讓他一次也沒摸郵袋，焙茶喝到一半他看了門口卻沒有站起來。

四種後記的最後都會依當晚泡的茶多一句（`tea_afterword`），三種茶各一句，寫成四種結局都成立的樣子：薄荷茶放進郵袋側袋、夜班休息時喝完才去下一區，洋甘菊讓他記得那種不用趕的感覺，焙茶讓他試著喝完一杯再出門。洋甘菊這句不以喝蜂蜜茶睡著為前提。

四種結局的收尾各有一個林澄的二選一，回應留在後記：今天簽收後，雨航問休假第一天該做什麼，可說什麼都不排，或說要他自己回答；寄往七年後時，可陪他把日期存進行事曆，或請他告訴一個會問他的同事；放進紀念盒時，可陪他蓋好盒蓋，或讓盒蓋留一條縫；拒絕簽收時，可把藍色信放回他郵袋最底下，或在他身後說信會一直在這裡。

蜂蜜洋甘菊的夢醒後，雨航會先摸郵袋：可以告訴他睡著的幾分鐘沒有漏信，他在末班車上不再硬撐，〈今日簽收〉後記裡休假第一天睡到中午；也可以問夢裡的車站，末班車窗外會閃過那座短月台，〈退回過去〉後記裡他在海邊車站的長椅坐了一會。焙茶讓他話說到家就起身要走：可以讓他走到門口，他握著門把後自己坐回來，走向空店面時也自己轉回方向，〈查無此人〉後記仍留著這個動作；也可以請他把茶喝完，走向空店面時他說手裡空了，〈今日簽收〉後記裡他在家喝完一杯焙茶才出門。薄荷路線不出現這些段落。

拼信前談守約時，若有葉暖的首次結局，可以告訴雨航上一夜有人帶著他父親代送的食譜卡來過；葉暖四種結局各讓雨航得出不同的想法，並在〈今日簽收〉後記裡讓他去晨麥買麵包、在〈查無此人〉後記裡想起父親送了兩次才送到。沒有前夜結局時不出現。同版也修正老郵局派送簿在〈留一口給妳〉之後誤用〈明天仍會出爐〉內容的句子。

拼信後、簽收選項旁另有三個可略過的追問。在站牌下問過妹妹時，可問雨航有沒有一句話想對她說，寫在明信片清單底下，或只對空椅子說出那把還沒賣的吉他。可問他七年替別人蓋過幾次章，讓他在紙巾上先蓋一次自己的名字。試過空店面鑰匙時，可陪他把鑰匙寄回房東，或先留在鑰匙圈上。各回答依結局留在四種後記。

在站牌下陪雨航安靜等過車後，他會反過來問林澄一個問題：有沒有一封一直收到、卻沒回的信。這是訪客第一次問起店員自己。林澄可以說出父親每年寄來、字很少的卡片（與終章童年住處的描述一致），雨航說寄件的人每年寫同一個地址，有時是在確認那個地址還對；也可以說今晚先送他的信，雨航便說她跟自己一樣先送別人的，不再追問。兩種回答都在章末旁白留下林澄自己的一句，並各在四種後記留下雨航後來的回應。沒有陪他安靜等車時不出現。

開場可逐一查看 PRD 列出的四項觀察：只有藍色信濕透的郵袋、每個「明年」底下被擦掉的日期、妹妹做的木製書店，以及他不肯說出的住處；也可直接請他放下郵袋。老郵局與末班車之間有等車的站牌，可問妹妹「她起頭，我收尾」的性格、他為何總接夜班，或只陪他安靜等車；末班車與空店面之間，可指出他繞路、問一個人開店算不算違背約定，或問父親當年那句「誰來休假」。三處都可直接略過；聽過的內容會在拼信前談話、今日簽收的休假單、退回過去的寄件地址與查無此人的後記中回響，略過則不出現。

## 路線與信

雨航帶著唯一淋濕的藍色信、停在「明年再開始」的派送簿與木製書店鑰匙圈進門。泡茶後，玩家依郵戳、雨痕與自己的字跡選三個投遞地點。每個線索在四個地址都有對應片段；走對可核對真實記憶，走錯則看見雨航當年可能選擇的另一種生活，仍能繼續。同一地址不能重複選，走到第二站時重載仍會保留路線與片段。老郵局、末班公車、空店面與夜行書店門外各有三件可逐一查看的物件，也可先離開；四片信紙仍按主線取得。拼信前可從妹妹的明信片、雨航親簽的租約，或他目前想如何處理信件切入談話；明信片與租約是否實際查看會改變回應，不阻斷任何結局。四片拼好後可查看逐年重寫的墨跡，再選過去、現在或未來的一枚郵票。查看老郵局派送簿時，葉暖先前四種結局各有不同回應：分享原配方、重新開店、休息一週或描重舊字。玩家可進一步比對父親兩次代送的郵戳與雨航每年改寫的藍色信，也可先將簿子收好。這項推理會在拼信前的談話與章末手冊留下回聲，不會替雨航決定簽收方式，也不阻斷四結局。

信不是預言，而是雨航在妹妹離世後每年寫給自己、又不肯寄出的話。完整理解且貼「現在」才能選「今日簽收」；「未來」可留下下個月的明確行動，並在第六夜開場再次與他交談，「過去」可放下共同開店計畫。拒絕簽收會走向「查無此人」。四個結局都有後記，並揭露藍色信上七年後的郵戳刻著書店門牌。

路線、信片和郵票即時寫入本機存檔。第五夜結局有獨立快照與收藏，茶方「雨航的薄荷檸檬紅茶」於完成後出現。茶席選薄荷罐後，可在注水前加入或取回檸檬片，並量取 0–30 毫升淡紅茶；選洋甘菊或焙茶可分別加入蜂蜜或蘋果乾。用量與配料選擇都會存入草稿，改變雨航喝茶時的回應與契合分數。

## 驗證與限制

Ink 編譯、四結局路徑、逐節還原、錯路可繼續、拼信前談話的已查／未查證據分支、信片與舊存檔預設值已測試。桌面／手機 Chromium 已實際走完最佳結局，並重載檢查檸檬片、淡紅茶用量、老郵局物件、投遞路線與郵票；三次錯路另從有效路線存檔驗證不同生活片段、禁止重複站點、第二站重載與回書店。其他三結局已從最終選擇前的有效存檔接續，在桌機／手機瀏覽器核對結局與收藏；尚未逐條從開場重玩。

書店對話已有雨航透明立繪，老郵局、末班公車、空店面與書店門外皆有專屬桌機／手機背景。四段場景已在桌機／手機 Chromium 完整路線核對圖片載入與對話畫面；PRD 的 45–55 分鐘時長尚未真人測量；快讀模型下首選路線約 40.8 分鐘，仍需節奏試玩。
