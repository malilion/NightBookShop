# 第四夜：葉暖〈沒有送到的生日麵包〉

故事原稿為 `story/chapters/ch04_yenuan.ink`，新版獨立編譯為 `yenuan-chapter-4`，舊版 Ink JSON 保留供原有存檔讀取。完成若音章後才可從章節選單開始；若音的首次結局會改變葉暖抵達時的對話，若音仍被掌聲困住的結局還會改變葉暖查看週年招牌時的回應。中途可在茶席、爐火、食譜與對話存檔，結局會留下獨立章節快照及收藏。

## 遊玩路線

葉暖帶焦掉的生日麵包、未拆封的蠟燭及母親食譜卡走進書店。玩家可將一片蘋果乾加入焙茶壺，材料與茶席進度會自動存檔；原味焙茶仍可繼續。泡茶後，用三次回應調整爐火：催促升溫，長久不回應降溫，等待或詢問讓火維持在可傾聽的範圍。四段記憶依序是清晨廚房、週年活動、醫院走廊及老烤箱，每處有三件可獨立查看的物件，也可先離開。醫院語音需先問葉暖，再由她決定播放或保留，劇情不以「這不是妳的錯」代替她自己的理解。

食譜三片正面是做法，背面是母親給葉暖的短箋。兩面都拼對並翻閱，才取得完整理解；玩家仍能留白並繼續。最後可由葉暖選擇保留母親原配方，或加入自己喜歡的柚子。結局選項包括新麵包、原配方重新上架、休店一週，以及要求完全複製。最佳結局需雙面食譜完整、爐火平衡，且選擇新的味道。

後記都揭露食譜卡上早於葉暖出生的夜行書店月亮標誌，以及書店桌沿上林澄童年的身高線。收藏含四款書籤及「葉暖的焙茶蘋果茶」。蘋果乾可在茶席加入並影響葉暖的第一段回應；共用製茶影片仍未按材料呈現不同畫面。

## 驗證與限制

Ink 編譯、四結局定向路徑、爐火與食譜計分、舊存檔預設欄位，以及桌面／手機 Chromium 的最佳結局流程均已測試。瀏覽器流程檢查爐火及食譜中途重載、守夜手記與收藏。其他三結局已從最終選擇前的有效存檔接續，在桌機／手機瀏覽器核對結局與收藏；尚未逐條從開場重玩。

清晨廚房、週年活動、醫院走廊與熄火的老烤箱皆有桌機及手機專屬背景；書店對話已有葉暖透明立繪。PRD 的 40–50 分鐘時長尚未經真人閱讀測量，現有文字量也未達該目標。
