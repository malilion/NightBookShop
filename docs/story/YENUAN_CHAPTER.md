# 第四夜：葉暖〈沒有送到的生日麵包〉

故事原稿為 `story/chapters/ch04_yenuan.ink`，新版獨立編譯為 `yenuan-chapter-19`（擴寫篇幅，見下段），舊版 `-1` 至 `-18` Ink JSON 保留供原有存檔讀取（`-16` 新增嚐到焦麵包「甜的」時的含淚立繪）。完成若音章後才可從章節選單開始；若音的四種首次結局會分別改變葉暖抵達時，以及林澄查看週年招牌時的想法。中途可在茶席、爐火、食譜與對話存檔，結局會留下獨立章節快照及收藏。

選了「問她現在若再忙不過來，會先找誰幫忙」或「問她若這次麵包仍烤焦，會怎麼做」的人，四種後記各多一句：熟客、隔壁店主和學徒三個名字一直排在她心裡，以及麵包烤焦時先讓它冷下來再找原因。這些選項都不是選單的第一項，首選路線不會經過，篇幅不變。

週年活動的記憶進場時，兩種非首選的茶各多一句：薰衣草伯爵讓她像在看別人家的店，蜜香紅茶讓她看見抹布時手指又動了一下。這些句子只在非首選的茶出現，不改變篇幅測試量的首選路線。

拼信開始前也會依當晚的茶多一句（`tea_before_letter`），讓茶在中後段留下回響：焙茶的焦香像晨麥打烊後的味道，薰衣草伯爵之後她不再說「那個女兒」，蜜香紅茶之後她的手放在膝上、不再找抹布。

四種後記的最後都會依當晚泡的茶多一句（`tea_afterword`），三種茶各一句，寫成四種結局都成立的樣子：焙茶成為櫃台後那壺給自己的茶，薰衣草伯爵讓她在打烊後試著用「我」說今天，蜜香紅茶讓她試著擦完三遍就坐下。

填食譜最後一格前，可以聽葉暖問起林澄的母親。林澄可以說每年過年和母親在姨媽家包餃子、什麼都談，只有小時候搬家那一年不提（與終章童年住處的描述一致），葉暖說自己和母親一起揉了二十年麵團，最想問的那句也沒問；也可以說自己很少打電話回家，葉暖不叫她去打，只說若打了，就說今天吃了什麼。兩種回答在章末身高線旁留下林澄的一句，並在四種後記各留下葉暖後來的做法。

開場可逐一詢問 PRD 列出的觀察：被劃掉的等待、手背上重複在同一季節留下的燙痕、每年新買卻從未點燃的蠟燭、替人切麵包自己卻不吃，以及黑貓如何叼走食譜卡、引她追到書店。從老烤箱回到櫃台後，可請她切開那顆每年天亮前都會丟掉的焦麵包：裡面其實沒有焦，她可以吃下中間一片，或先留到明早再看。四種結局的後記各自回應這些選擇；略過則不出現。

填食譜最後一格前，林澄會依若音的首次結局想起她的最後一小節，並可問葉暖最後一格想寫給誰吃。若音走到〈掌聲的回音〉時，葉暖會問照抄是不是就不用決定；其他情況她說想寫給明天早上的自己。這一行出現在〈留一口給妳〉的新配方卡上，在〈永遠相同的味道〉後記裡則被母親的舊字描滿。沒有前夜結局時不出現。

`yenuan-chapter-19` 擴寫：首選路線（焙茶、小遊戲完成良好）由約 6,400 字／31 分鐘增至約 9,900 字／41 分鐘（`tests/unit/chapter-length.test.ts` 的快讀模型）。不新增劇情事實或結局，只加深既有段落：開場籃子與圍裙的細節、她說「媽媽的」不改口；焙茶專屬的 `hojicha_talk`（母親打烊後用烤箱餘溫焙茶、「焦和香只差一點點」）；爐火平衡時說出活動當天早上母親來電說「辦小一點也沒關係」；清晨廚房的燈、收音機與母親手上的燙痕；週年活動的隊伍、隔壁花店老闆娘兩次說要幫忙顧收銀、帳本上「當天記得吃午餐」；醫院走廊的扶門護理師、聽完語音後「我一直記成她在催我回去」；老烤箱門把的布套與旋鈕旁的紅點；焦麵包吃下後「這幾年我扔掉的，都是這樣的麵包」；拼信後讀到「店是我們一起開始的，但妳要把它做成自己的」；〈明天仍會出爐〉當天黑板上的「葉媽媽的配方」。另有三個可略過、放在選單第一項的追問：觀察時問晨麥是什麼樣的店（`asked_shop`，在〈留一口給妳〉與〈明天仍會出爐〉後記留下黑板）、清晨廚房問母親怎麼教她收口（`asked_dawn_hands`）、老烤箱前問上一次讓晨麥休息是什麼時候（`asked_rest`，在〈休息中的晨麥〉後記回應）。

## 遊玩路線

葉暖帶焦掉的生日麵包、未拆封的蠟燭及母親食譜卡走進書店。玩家可將一片蘋果乾加入焙茶壺，材料與茶席進度會自動存檔；原味焙茶仍可繼續。茶泡得契合又到位時，她想起母親曾為她留一杯茶；合適的茶讓她坐下；普通的茶可追問烤箱安靜時會想起什麼，或先陪她握暖杯子；失衡的茶揭露她把不如預期都當成自己要補做的工作。任何品質都可繼續爐火。

薰衣草伯爵讓她放鬆，卻把那晚說成「有個麵包師的女兒」的故事：玩家可以讓她先用第三人稱說下去，到醫院走廊她會自己說不下去別人的故事；也可以輕聲請她試著用「我」說一句，她只說出「我……說了再五分鐘」便請妳慢一點，到醫院才把句子說完。蜜香紅茶讓她起身擦同一塊櫃台：玩家可以拿另一塊抹布陪她擦，她邊忙邊說出週年那晚的手不能停；也可以收走抹布請她坐下，她才承認手一空就只剩那天晚上。薰衣草的兩種回應在醫院走廊回來，第三人稱那條另留在〈明天仍會出爐〉的後記；紅茶的兩種回應在離開週年活動前回來，並留在〈休息中的晨麥〉的後記。焙茶路線不出現這些段落。泡茶後，用三次回應調整爐火：催促升溫，長久不回應降溫，等待或詢問讓火維持在可傾聽的範圍。四段記憶依序是清晨廚房、週年活動、醫院走廊及老烤箱，每處有三件可獨立查看的物件，也可先離開；取回紙片後另有依已看線索改變的收束與兩種追問。醫院語音需先問葉暖，再由她決定播放或保留，劇情不以「這不是妳的錯」代替她自己的理解。

查看週年招牌後，可問葉暖滿座以外最想讓母親看見什麼，也可先放回招牌。追問會讓她指出兩人筆跡中的歪蘋果，並在活動傳單與最後填配方時再次提起；這不抵銷醫院來電，也不替她決定結局。

食譜三片正面是做法，背面是母親給葉暖的短箋。兩面都拼對並翻閱，才取得完整理解；玩家仍能留白並繼續。填最後一格前，玩家可先問葉暖想替自己留下哪一口，也可催她趕上隔日營業；再由她選擇保留母親原配方，或加入自己喜歡的柚子。結局選項包括新麵包、原配方重新上架、休店一週，以及要求完全複製。最佳結局需雙面食譜完整、爐火平衡、確實談過不以成品懲罰自己，且選擇新的味道。

後記都揭露食譜卡上早於葉暖出生的夜行書店月亮標誌，以及書店桌沿上林澄童年的身高線。收藏含四款書籤及「葉暖的焙茶蘋果茶」。蘋果乾可在茶席加入並影響葉暖的第一段回應；共用製茶影片仍未按材料呈現不同畫面。

四種結局的收尾場景各多一個由林澄回應的小選擇，並留在對應後記：〈留一口給妳〉可接過一片一起吃，或請葉暖把第一片留給常客試吃；〈明天仍會出爐〉在常客問「跟以前一樣嗎」時，可讓她說一樣，或說「是我烤的，可能差一點」；〈休息中的晨麥〉在她擔心有人敲門時，可陪她補一行留言方式，或讓門關著；〈永遠相同的味道〉在她問「如果下次差了一點呢」時，可保證只要照著做就不會差（介入加深），或不回答、把茶推給她。

## 驗證與限制

Ink 編譯、四結局定向路徑、爐火與食譜計分、舊版 `-7` 的逐節還原，以及桌面／手機 Chromium 的最佳結局流程均已測試。瀏覽器流程檢查週年招牌選擇前、爐火及食譜中途重載、守夜手記與收藏。其他三結局已從最終選擇前的有效存檔接續，在桌機／手機瀏覽器核對結局與收藏；七夜從空白收藏依序連玩也在兩版通過。替代結局尚未逐條從開場重玩。

清晨廚房、週年活動、醫院走廊與熄火的老烤箱皆有桌機及手機專屬背景；書店對話已有葉暖透明立繪。PRD 的 40–50 分鐘時長尚未經真人閱讀測量；以快讀模型估算，首選路線約 41 分鐘，慢讀（每分鐘 250 字）約 56 分鐘。
