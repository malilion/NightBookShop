# PRD 完成度與待驗收項目

此表以 `midnight-bookshop-story-chapters-v1.md` 與 `midnight-bookshop-technical-architecture-v1.md` 為範圍。程式通過測試只證明該測試覆蓋的流程；「可玩」不等於時長、美術或正式版驗收完成。

| 要求 | 目前證據 | 尚需工作 |
| --- | --- | --- |
| 六位訪客與林澄終章 | 七份獨立 Ink 原稿、編譯 JSON；每章四結局定向單元路徑；若音的三種曲子收尾各需呼應先前聽見的雨聲、宴會廳聽眾或手傷，才可走最佳理解結局。七夜各有一條從開場到結局的桌機／手機完整路線；其餘結局由最終選擇前的有效存檔接續，28 種結局皆在桌機與手機 Chromium 核對畫面、存檔及收藏 | PRD 要求的內容長度、節奏與真人閱讀驗收；替代結局尚未逐條從開場重玩 |
| 章節解鎖、書籤、後記、存檔 | 收藏 IndexedDB、各章首次快照、舊欄位預設值；中途重載 E2E；下一夜開店櫃台及開場對話會依前夜首次結局呈現不同事件。桌機與手機 Chromium 已從空白收藏直接連玩七夜，沒有預先解鎖；28 種結局各核對收藏寫入 | 交叉事件在更多中段探索與選擇中的回應 |
| 每晚開店、觀察、茶、記憶與拼信 | 七夜皆可整理櫃台、查看夜況與可探索區域、核對八種茶；準備進度可中途保存。靜蘭與柏言各三段、若音、葉暖、雨航與海明各四段、終章三段記憶可逐一探索三件物件；已讀狀態可重載。柏言列車的三則工作通知需逐則暫停，母親訊息可選擇回覆，進度可中途重載。柏言的洋甘菊可加蜂蜜，觸發身體警訊與求助對話；若音的薰衣草茶另解鎖童年手記；葉暖可加入蘋果乾、雨航的薄荷茶可加檸檬與定量淡紅茶，另可選蜂蜜洋甘菊或蘋果焙茶，海明可加入海鹽焦糖；材料存入本機並改變各自的第一段回應。各章有觀察標記及茶席；第二至六章專屬互動；終章六夜地圖；拼信碎片可用方向鍵移動 | 各章專屬製茶演出與自由配方混茶系統 |
| PRD 章節時長 | 尚無真人計時；第五夜已補四段記憶細節及一段依探索證據回應的拼信前談話 | 依各章 35–60 分鐘目標擴寫可選對話與可探索細節，安排真人閱讀計時 |
| 六章交叉細節與隱藏空間 | 七夜已分別留下靜蘭聽見的四音、柏言母親的校刊、若音的尾牙節目單、葉暖食譜的代送郵戳、雨航妹妹的燈塔照片、海明哼出的旋律；終章地圖中心可進入書架後收藏室，查看六格信櫃、身高線與停鐘；前一章首次結局會改變下一夜櫃台及開場對話，靜蘭被代為決定的結局會改變柏言在辦公室收信時的反應，柏言繼續加班會改變若音閱讀尾牙節目單的回應，若音受掌聲困住會改變葉暖查看週年招牌時的反應，葉暖讓晨麥歇一週會改變雨航查看老郵局派送簿的回應，雨航選擇寄往過去會改變海明查看潮汐圖的回應，海明只留下英雄傳記會改變林澄查看信櫃的回應 | 其餘結局變化尚未進入後續中段探索與操作；跨章線索串成地圖以外的可操作推理仍待補 |
| 視覺資產 | 第一夜三個記憶場景、第二夜三段、第三夜四段、第四夜四段、第五夜舊郵局、第六夜四段記憶，以及終章收藏室與童年書店各有桌機／手機背景。第二、三、四夜全段及第六夜新增三段已在桌機／手機完整流程驗證圖片載入、物件操作與對話畫面；第二、三、四夜專屬素材包也通過離線重載測試。六位訪客的透明立繪已接入各自書店對話與章節選單；第一夜另有無介面文字的桌機／手機書店背景 | 其餘記憶場景、表情變化及逐場渲染檢查 |
