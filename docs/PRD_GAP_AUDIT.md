# PRD 完成度與待驗收項目

此表以 `midnight-bookshop-story-chapters-v1.md` 與 `midnight-bookshop-technical-architecture-v1.md` 為範圍。程式通過測試只證明該測試覆蓋的流程；「可玩」不等於時長、美術或正式版驗收完成。

第二夜辦公室新增可略過的跨夜提問：靜蘭四種首次結局會讓林澄以不同方式問柏言信要先由誰讀；柏言選擇先自己讀，拼信前再確認收件人可留白。新版 `boyan-chapter-11` 通過四種前夜結果的定向路線，以及桌機／手機 Chromium 的選擇、存檔與重載；舊 `-10` 編譯檔保留並通過四結局路線。此擴充仍需真人驗證前夜呼應是否容易理解。

終章收藏室現依前五夜各自的首次結局，在第一至五格顯示不同的信件後續；第六格沿用海明四種結果。新版 `lincheng-chapter-9` 啟動時從章節快照取得結局，舊 `-8` 編譯檔保留供舊存檔續讀。前五夜各四種組合通過 Ink 定向路線，靜蘭與海明真實章節快照接入的終章完整路線在桌機／手機 Chromium 通過；其餘組合與真人閱讀推理仍待瀏覽器驗收。

PWA 首裝現在只預快取第一夜的 Ink JSON；第二夜至終章在進章時下載並留在持久故事快取。新 Service Worker 安裝時會先從舊 Workbox 快取轉存歷史 JSON，再清理舊預快取，讓已下載章節與舊版存檔仍可離線續讀。桌機／手機 Chromium 的六個後續素材包、舊第三夜存檔及第一夜離線流程共 16 項通過；整合建置的首裝快取由 7933.3 降至 5891.5 KiB。真正跨版本部署、低儲存空間與實機瀏覽器更新仍待驗收。

第三夜新版 `ruoyin-chapter-9` 在雙面拼信後加入可選的寫曲對話：若音可親自重談童年四音的停頓、想讓誰聽新旋律與手累時的休止符。即使玩家先前略過對應記憶物件，只要在此刻聽她說明，最後一小節仍可真誠呼應；若一路略過，最佳理解結局仍不會憑空開啟。舊 `-8` 編譯檔保留供存檔續讀。桌機／手機完整第三夜流程已通過，仍未證明 40–50 分鐘真人時長。

手機主要閱讀畫面已量測並加大茶壺蓋、沙漏、茶匙、滑桿及製茶動畫暫停鍵的操作區：首頁、設定、章節選單、對話、第一夜茶席與倒茶動畫通過 44×44 CSS px 自動檢查。茶架兩排罐子與名稱也不再重疊。共用拼信、空白與解鎖後收藏、六種章節小遊戲的初始及操作後畫面，以及第一夜結局也通過同一量測。其餘結局狀態、實機觸控、對比與讀屏流程仍待逐項審核；同期茶屋模組的錯誤修復後，整合建置已恢復通過。

第二夜的濃紅茶現在讓柏言重新進入工作狀態，玩家須多談一輪才能讓他自行合上筆電；薄荷茶能協助他把今晚、明早與求助事項分欄，但不會立刻令他放鬆。兩種茶各有兩種回應選擇，可中途重載。新版為 `boyan-chapter-10`，舊 `-9` 編譯檔保留供存檔還原。

第一夜原本沒有 PRD 列為代表物的白山茶。現在靜蘭可自行取出先生留下、夾在購物清單裡的壓乾花，玩家能詢問並記入手記；回到書店後，她會把白山茶與岳川的藍信分開放，兩段生活都不被抹去。此物件可略過且不阻斷四條結局。桂花烏龍現在也會帶出兩人在桂花樹下輪流讀詩的記憶，沖泡品質不足仍可聽見。病房記憶新增可略過的家人追問，說明母親原先反對她遠行，但當晚留下仍是靜蘭自己的決定；回到書店拼信時會呼應。記憶場景現會保留三件物件以外的對話選項，追問在桌機／手機 Chromium 可見、可點選且可重載。新版 `jinglan-chapter-7` 由 `main.json` 載入，更新前的編譯檔完整保留為 `jinglan-chapter-6.json`，供既有存檔還原。

第六夜至終章的地圖揭露順序已調整：第六夜照片仍揭露童年林澄與店主，但六張紙的中心不先說出；終章須由玩家翻紙並接好五段關係，才看見以夜行書店為中心的城市地圖。新版 `haiming-chapter-12`、`lincheng-chapter-8` 之外保留舊編譯版本供存檔接續；未完成地圖會回到比對操作。

終章已按 PRD 收斂〈不會天亮的書店〉：只在開場拒坐、拒讀自己的信時進入，不再能在讀信後選到與後記矛盾的同一結局。林澄現在可追問店主將童年保管請求延伸為成年守夜的責任；桌機／手機 Chromium 四種終章結局與新追問已核對。

第六夜潮汐圖現在對雨航四種首次結局各有不同回應；玩家可追問海明如何向顧川交代自己曾能搭上早班船，這句會留到拼信前。`haiming-chapter-11` 的定向單元路線與桌機／手機完整流程已通過，舊 `-10` 存檔版本保留。同期茶席型別錯誤修復後，最新一次完整 `npm run build` 已通過；仍須以後續驗收確認實機、真人時長及其餘 PRD 差距。

收藏頁現可在終章前比對六位訪客的跨夜線索：只顯示已收存的訪客與實際發現的證據，選兩夜配對時須具備對應線索；錯誤配對可重試。手記累積重玩發現的線索，並從舊存檔補回仍可讀到的證據；成功連線會在終章六夜地圖供玩家翻閱，但終章仍須自行完成翻頁與連線。桌機／手機 Chromium 的缺證據、錯誤配對、成功配對及重載流程已通過；其餘結局對後續故事操作的變化仍待擴充。
