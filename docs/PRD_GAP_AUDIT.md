# PRD 完成度與待驗收項目

此表以 `midnight-bookshop-story-chapters-v1.md` 與 `midnight-bookshop-technical-architecture-v1.md` 為範圍。程式通過測試只證明該測試覆蓋的流程；「可玩」不等於時長、美術或正式版驗收完成。

| 要求 | 目前證據 | 尚需工作 |
| --- | --- | --- |
| 六位訪客與林澄終章 | 七份獨立 Ink 原稿、編譯 JSON；每章四結局定向單元路徑；若音的三種曲子收尾各需呼應先前聽見的雨聲、宴會廳聽眾或手傷，才可走最佳理解結局。七夜各有一條從開場到結局的桌機／手機完整路線；其餘結局由最終選擇前的有效存檔接續，28 種結局皆在桌機與手機 Chromium 核對畫面、存檔及收藏 | PRD 要求的內容長度、節奏與真人閱讀驗收；替代結局尚未逐條從開場重玩 |
| 章節解鎖、書籤、後記、存檔 | 收藏 IndexedDB、各章首次快照、舊欄位預設值；中途重載 E2E；下一夜開店櫃台及開場對話會依前夜首次結局呈現不同事件。桌機與手機 Chromium 已從空白收藏直接連玩七夜，沒有預先解鎖；28 種結局各核對收藏寫入 | 交叉事件在更多中段探索與選擇中的回應 |
| 每晚開店、觀察、茶、記憶與拼信 | 七夜皆可整理櫃台、查看夜況與可探索區域、核對八種茶；準備進度可中途保存。靜蘭與柏言各三段、若音、葉暖、雨航與海明各四段、終章三段記憶可逐一探索三件物件；已讀狀態可重載。柏言列車的三則工作通知需逐則暫停，母親訊息可選擇回覆，進度可中途重載。柏言的洋甘菊可加蜂蜜，觸發身體警訊與求助對話；其茶種、配料及沖泡品質另帶出共鳴記憶、合適回應、普通品質的可選追問或失衡時的另一條情緒線索。若音的薰衣草茶可解鎖童年手記；葉暖可加入蘋果乾、雨航的薄荷茶可加檸檬與定量淡紅茶，另可選蜂蜜洋甘菊或蘋果焙茶，海明可加入海鹽焦糖；材料存入本機並改變各自的第一段回應。雨航三個地址線索各有對應真實記憶與錯路的另一種生活片段，站點不可重複，路線可中途重載。各章有觀察標記及茶席；第二至六章專屬互動；終章六夜地圖；拼信碎片可用方向鍵移動 | 第三至六夜的製茶品質回應、各章專屬製茶演出與自由配方混茶系統 |
| PRD 章節時長 | 尚無真人計時；第二夜補三段記憶證據、依探索改變的收束與拼信前選擇，固定首選路線由 3,109 增至 6,011 字元、75 增至 122 段。第三夜四段記憶在取信後加入依已看物件改變的對話與各兩種追問。第四夜四段記憶也加入依證據改變的收束與追問，填配方前須辨認想紀念母親或只怕做錯。第五夜已補四段記憶細節及拼信前談話。第六夜固定首選路線由 3,229 增至 6,466 字元、82 增至 136 段。這些量測未包含真人閱讀速度，不能證明各章目標時長 | 依各章 35–60 分鐘目標繼續擴寫有意義的可選對話與探索細節，安排真人閱讀計時 |
| 六章交叉細節與隱藏空間 | 七夜已分別留下靜蘭聽見的四音、柏言母親的校刊、若音的尾牙節目單、葉暖食譜的代送郵戳、雨航妹妹的燈塔照片、海明哼出的旋律；終章地圖中心可進入書架後收藏室，查看六格信櫃、身高線與停鐘；前一章首次結局會改變下一夜櫃台及開場對話，靜蘭被代為決定的結局會改變柏言在辦公室收信時的反應，柏言繼續加班會改變若音閱讀尾牙節目單的回應，若音受掌聲困住會改變葉暖查看週年招牌時的反應，葉暖讓晨麥歇一週會改變雨航查看老郵局派送簿的回應，雨航寄往七年後時會在第六夜先重逢並談下個月的第一步，寄往過去則改變海明查看潮汐圖的回應，海明的四種結局都會改變林澄查看第六格信櫃與回應店主的內容 | 其餘結局變化尚未進入後續中段探索與操作；跨章線索串成地圖以外的可操作推理仍待補 |
| 視覺資產 | 七章目前列出的 25 段記憶各有桌機／手機專屬背景。第五夜四段及終章三段已在桌機／手機完整流程檢查圖片載入、對話與場景切換；終章童年住處的轉場完成畫面也已目視檢查。第二至六夜及終章各有按章離線素材包測試。第六夜「白色房間」改為暖白牆、無海窗景，桌機／手機實際畫面及離線載入已核對。六位訪客透明立繪已接入書店對話與章節選單；童年林澄與店主已有獨立立繪，依第六夜與終章劇情標記出場並納入離線素材包；第一夜另有無介面文字的桌機／手機書店背景 | 人物表情變化、各場景更完整的演出，以及實機視覺驗收 |
| 正式版操作與無障礙 | 文字速度、大小、減少動態、對話鍵盤、茶席鍵盤、拼頁方向鍵及手機直向可用 | 觸控目標與對比審核、螢幕閱讀器流程、實機 Safari／Android |
| 正式版系統 | PWA 離線第一章、後續章節啟動時下載專屬背景與立繪、按需快取製茶影片、音量設定、本機存檔、建置與測試；建置檢查確認 JS gzip、首頁圖片及安裝預快取低於 PRD 預算，第二至六夜及終章素材包離線測試通過。收藏頁已有 28 格書籤書架、七夜故事句與主線線索、茶方、七則可解鎖後日談及四枚依收藏回溯點亮的徽章 | 實際逐章首批網路傳輸、影片動畫容量及桌機／手機 FPS 量測；完整回顧的真人閱讀與視覺驗收、多語系架構；雲端存檔是 PRD 可選項 |
