# 3D 茶罐與茶具

2026-09-22。將茶席的平面器物換為同一組 Three.js 模型渲染的透明素材，保留現有拖曳、鍵盤、觸控及水量規則。這是 3D 預渲染美術，不是可自由旋轉的即時 3D 茶桌。

## 模型與材質

- 八種茶罐：深綠、赤褐、薄荷青、灰綠、赭紅、米白、紫灰與深棕釉色。木蓋、金屬口沿、罐口內壁、弧面紙標與乾茶葉分別建模。
- 茶壺、壺蓋與杯碟：平滑器型、柔和釉面、窯燒斑點、釉色細微變化、細金邊與內壁。把手改用與器身一致的陶瓷，減少原本厚重的金屬外觀。
- 銅水壺：低矮圓腹、槌目凹凸、獨立壺蓋、胡桃木握柄與蓋鈕、金屬提梁和接點；鵝頸壺嘴逐漸收細，包含壺口內孔。茶匙仍有凹入匙面和圓滑柄，空匙與有茶葉分開渲染。
- 茶湯：以半透明、非金屬液面、中心深淺、邊緣彎月面和少量細泡表現深度；水流加入透光材質，互動水線增加細高光。`teaLiquorColors` 與茶罐辨識色分開，薰衣草伯爵仍呈紅茶色。這是美術近似，不是即時流體或光譜吸收模擬。
- 光線改為單一寬柔光、側面反光條與頂光的程序式攝影棚環境，減少多個強光斑造成的塑膠感。
- 茶葉使用雙面薄片網格：尖端、不對稱邊緣、破口、摺痕與分岔葉脈。八種茶分別使用不同的葉色、長寬比例及散葉尺度；桂花烏龍、茉莉綠茶、洋甘菊與薰衣草伯爵另有花材模型。罐內、茶匙、未注水的壺與注水後的壺都依茶種預渲染。葉片基礎網格共用，花材以美術近似呈現，並非植物學模型。
- 60 個 WebP 狀態涵蓋 16 個茶罐開／關、16 個不同茶色的壺／杯、16 個茶種專屬乾葉壺與滿匙、6 個基本器具，以及四個清水／獨立液面狀態。主要操作器物全部透明背景，比例和位置由 manifest 提供。

素材由原生程式模型製作，沒有外部照片、AI 生圖或下載的模型。材質細紋使用固定亂數種子；同一模型同時用於 Remotion 影片。

## 重建

```sh
npm run render:tea-props
npm run video:render -- --publish
npm run video:render:complete -- --publish
npm run build
```

可先執行 `npm run render:tea-props -- --preview`，只輸出五種代表器物到 `output/tea-props-preview/`，不覆寫遊戲素材或 manifest。

需要既有 Chromium、Three.js、sharp、FFmpeg 與 ffprobe。第一個命令在本機 4176 開啟渲染頁，依茶方產生 `public/images/tea-props/*.webp` 與 `src/data/teaPropAssets.json`；每張檢查透明與不透明像素都存在。後兩個命令會更新本機影片，並驗證雙格式、720p／30 fps／6 秒與完整解碼。工作結束會關閉 Chromium 和渲染伺服器。

- `video/src/tea-set.js`：共用模型、材質、影片與 `renderProp` 正交投影。
- `video/src/tea-leaves.js`：乾／濕葉片網格、程序式葉脈貼圖與固定種子變化；取茶落葉與泡茶影片使用相同模型。SVG 備援也改為尖葉輪廓。
- `video/src/tea-surfaces.js`：攝影棚反射環境、槌目、釉色及茶湯深淺貼圖。
- `scripts/tea-props/index.html`：單次工作階段重用各器具的渲染器。
- `scripts/render-tea-props.mjs`：批次輸出、透明度檢查、釉色與顯示範圍。
- `src/components/tea/TeaObject.vue`：預渲染圖、接觸陰影與原 SVG 備援。
- `src/services/teaInteraction.ts`：使用 manifest 的壺嘴投影來判定水流，不另外猜測圖中壺嘴位置。

素材與影片加入 PWA 預快取，Three.js 不進入遊戲 runtime。水位目前以空／有水兩種器物狀態表示，精確水量仍由百分比與水流呈現；湯色則連續變化；沙漏仍為動態 SVG。實體 iOS Safari 尚需驗證。

## 依茶種與時間變化的茶湯

`src/services/teaInfusion.ts` 以八種茶的漸變色表和該茶方建議秒數計算湯色：初注清水 → 建議時間的 20%（初染）→ 建議時間（適飲色）→ 2.4 倍時間（深色上限）。沿用遊戲最長 120 秒、三倍速沙漏；沒有水或茶葉時不顯色。這是遊戲美術規則，不是實驗室萃取模型。現在不依水溫與茶量調整色速。

- 壺與杯使用清水底圖，再疊上獨立的灰階液面。SVG 濾鏡只替液面染色，保留葉片遮擋、液面光澤、器身與把手顏色。共 44 個器物狀態，新增 `pot-water`、`cup-water`、`pot-liquor`、`cup-liquor`。
- 湯色由 `teaId / seconds / water / leaves` 推算，不增加存檔欄位。沙漏暫停就停止變色；讀檔還原秒數後自然還原湯色；重新整理茶席回到清水。提壺時沿用原規則停止計時，因此壺、倒茶水線、杯中茶與完成演出保持相同色相。
- 完成影片使用同一場景與鏡頭渲染的 180 格液面遮罩，以 `requestVideoFrameCallback` 對齊影片影格；不支援時退回 RAF。暫停／seek 同步，減少動態和影片失敗的海報使用第 0 格。只裁切液面，圖集 3228×855、348,626 bytes，不為每個顏色另存完整影片，也沒有 WebGL runtime。
- `npm run render:tea-liquor` 可獨立重建完成動畫液面圖集與 `src/data/teaLiquorFrames.json`。完成影片以 `--publish` 發布本機素材時會自動重建，鏡頭或器型修改後需讓兩者一起更新。若圖集載入失敗，回退原影片／海報，不阻止故事繼續。
