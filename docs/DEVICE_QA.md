# 實機與讀屏驗收清單

自動化已涵蓋的部分（每次發版前跑一次）：

| 範圍 | 指令 | 內容 |
| --- | --- | --- |
| Chromium 桌機／手機 | `npm run test:e2e` | 全部瀏覽器流程、觸控拖曳與雙指縮放（CDP 觸控）、離線 |
| Safari 引擎（WebKit）桌機／iPhone | `npm run test:e2e:webkit` | 同一套流程在 Safari 引擎上跑；觸控拖曳以滑鼠驅動同一組 pointer 事件；離線改由 `webkit-offline.spec.ts` 以自建伺服器斷線驗證 |
| WCAG 2.1 AA | `npx playwright test tests/e2e/accessibility-audit.spec.ts` | 七章 × 對話、選項、記憶、茶席、章節小遊戲、拼信、結局，加上首頁、設定、章節選單、收藏；第一夜另含高對比與放大文字。axe 規則與「量測背後實際畫素」的文字對比都必須零違規 |

以下需要真的手機或真人操作，自動化無法替代。每項記下裝置、系統版本、瀏覽器版本與結果。

## iPhone Safari（實機）

1. 以 Safari 開啟正式網址，加入主畫面後從主畫面開啟（PWA）。
2. 開始故事、完成開店準備，確認對話逐字、「顯示全文」、立繪與背景正常。
3. 茶席：用手指拖曳茶罐、茶匙、銅壺與茶壺，傾倒時水量與杯中茶湯變化；沙漏可點按開始／暫停。
4. 奉茶影片：有聲音（音量跟隨設定的音效）、可暫停與略過；靜音開關會讓它無聲。
5. 拼信：拖曳碎片進格、旋轉、翻面；**雙指放大到 175% 後仍能拖曳**（Playwright 的 WebKit 無法模擬雙指，只能在實機確認）。
6. 開飛航模式後從主畫面重開：第一夜存檔可續玩；已開過的後續章節背景與立繪仍在。
7. 背景音樂、雨聲、茶具音效在首次點按後才出聲；切到別的 App 再回來不會疊音。

## Android Chrome（實機）

同 iPhone 的 1–7；另確認系統返回鍵在對話框（選單、製茶影片）開啟時是關閉對話框，而不是離開遊戲。

## VoiceOver（iPhone）

1. 三指點按開啟「螢幕閱讀器」。開頭應先唸「前往主要內容」，再唸標題「夜行書店」。
2. 對話：每換一句，說話者與台詞由播報區自動唸出（`aria-live="polite"`），不必移動焦點；「繼續」與選項按鈕名稱即選項文字。
3. 記憶場景：物件按鈕唸「探索物件：…」。
4. 茶席：茶罐、茶匙、水壺、茶壺、沙漏都可聚焦並有名稱；以「輕點兩下並按住」拖曳，或改用鍵盤方式完成一杯茶。
5. 拼信：格子唸「信紙第 N 格，空白」或其中的句子；碎片以句子為名；「放大／縮小拼信工作區」可用。
6. 製茶影片：對話框標題唸出「把這一杯，放到…面前」，「略過動畫，繼續故事」可直接啟用。
7. 存檔狀態唸「進度自動保存在此瀏覽器」。

## TalkBack（Android）

與 VoiceOver 相同的 1–7；以「輕觸兩下」啟用、兩指滑動捲動。
