# 拼信操作

靜蘭第一章有三片信紙。滑鼠與觸控可以把桌上的碎片拖到信紙三格；已放好的碎片也能拖到別格，或拖回右側桌面。放進格子時會吸附並擺正。覆蓋已有碎片的格子時，原碎片回到桌面。

點選碎片，再點選格子，也能完成相同操作。按 Tab 聚焦按鈕後可用 Enter 或空白鍵選取及放置。選取後可按「旋轉 90°」或「翻到背面」查看紙片；翻回正面才能把該片算入拼信完成度。翻看「請不要等我」背面會記錄墨跡線索。原有「查看不同的墨跡」按鈕與多年後文字版本選項繼續保留。

七章共用的拼信工作區可用兩指縮放，也可用 44×44 CSS px 的放大、縮小按鈕在 100% 至 175% 間調整。放大會同步增大信紙格、碎片與文字，頁面仍可捲動；放大時信紙不會固定覆蓋下方碎片。縮放只影響當次畫面，不改動信件排序與存檔；重載後回到 100%。

三格位置、每片角度、正反面、墨跡觀察及文字版本都進入自動與手動存檔。舊存檔沒有角度與正反面欄位時，讀取時視為擺正、正面，不變動故事位置。拼信仍可留白或拼錯並繼續劇情。
