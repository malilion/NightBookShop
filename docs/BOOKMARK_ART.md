# 結局書籤插畫

二十八種結局各有一張獨立插畫，依 `src/data/bookmarkArt.ts` 的結局 ID 對應至 `public/images/bookmarks/`。收藏頁只顯示已解鎖的插畫；未取得的書架格維持缺頁。第一夜四張由 PWA 預快取，其餘隨對應章節的圖片包下載。

## 生成規格與提示詞

使用內建 `image_gen` 各別生成一張無文字、無邊框的直式插畫，再以 Sharp 輸出 384×1024 WebP（3:8，品質 82）。共同提示詞為：夜行書店的收藏書籤插畫；日系故事書水彩、水粉與細緻墨線；深夜藍 `#101722`、舊紙 `#f3e7d3`、琥珀金 `#d7b681`；手繪景深、明確的主體輪廓；不用可辨識文字、人臉、商標或通用奇幻符號。每張再加入下表的結局場景。
