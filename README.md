# 夜行書店 · The Midnight Bookshop

午夜至黎明，一杯茶、一封信，和一個還沒說完的故事。

目前可玩 **六位訪客與林澄終章**。第一夜有三段記憶與三片信紙；第二夜有三段記憶與四格辭職信；第三夜有四段記憶、四音回應與雙面拼信；第四夜有四段記憶、爐火傾聽與雙面食譜；第五夜有投遞路線、四段記憶、藍色信與三枚郵票；第六夜有守燈、四段記憶與可保留原句的紙船信。終章可比對六夜線索、為自己泡茶、拼回童年的信並走向四種結局。各夜都有四種結局及後記。八種茶共用可拖曳茶席；奉茶時播放該茶的專屬製茶影片，由林澄的雙手取茶、注水、倒茶，再把茶推到訪客面前。

標題頁的 **午夜茶席**（或直接開 `/tea.html`）是不需劇情進度的獨立製茶模式：讀懂五位深夜來客的口味，在風爐上親手煮水、調配兩種茶、把八種配料放進茶壺或茶杯，看著風味雷達隨浸泡時間變化，在每位客人的最佳時機提壺；七步完成度即時亮起。收集二十款特調，每天還有一張所有人相同、可分享成績的今日茶單。

## 本機啟動

需要 Node.js 22.12+ 與 npm。

```sh
npm ci
npm run dev
```

開啟終端顯示的本機網址。預設為 http://127.0.0.1:5173 。根目錄原始 PNG 已保留，WebP 已產生；只有更換素材時才需要 `npm run assets`。修改 `.ink` 後需重新執行 `npm run build:ink` 或重啟開發伺服器。

```sh
npm run lint
npm run typecheck
npm test
npm run validate:ink
npm run build
npm run test:e2e
npx playwright test tests/e2e/chapter-transfer-budget.spec.ts
```

首次跑瀏覽器測試若缺 Chromium：`npx playwright install chromium`。E2E 使用正式 `dist/`，先執行 build；自動啟動 4173 preview。最後一項命令量測已載入程式主體後，各章首次進入的資源請求。截圖位於 `output/`，失敗 trace 位於 `test-results/`，兩者不列入 Git。

## 已實作

- Vue 3 + TypeScript + Vite + Pinia + Router 的路由、元件、領域邏輯、儲存層分工。
- 標題、遊戲、六位訪客及終章目錄、收藏、存檔與閱讀設定；依完成順序開啟六夜與終章。
- Ink 原稿與可重複編譯腳本，tag 允許清單與 Story Bridge。
- 序章、靜蘭與柏言各三段記憶、若音、葉暖、雨航與海明各四段記憶；六位訪客與終章的記憶場景可逐一探索物件。各夜及終章有四種結局與後記。第三夜末揭露員工手冊第一頁，第四夜留下林澄童年的線索，第五夜串起不守時間順序的門牌，第六夜讓店主現身，終章由林澄決定信與自己的去向。
- 七夜開場可整理櫃台、查看夜況與可探索區域、核對八種茶；三項進度會自動存檔。第二夜起，櫃台與來客開場對話會按前一夜的首次結局出現不同事件，舊存檔直接回到原進度。
- 校刊室、病房走廊與月台各有獨立背景與可點選的線索物件；查看狀態從 Ink 選項還原，也保留對話選項與數字鍵操作。切換時淡化，減少動態效果會略過轉場。
- 八種不同釉色的 3D 茶罐，搭配陶瓷茶壺、銅水壺、茶杯與茶匙；支援開蓋、乾葉、空杯和茶湯狀態。
- 八種茶自由選罐；拖曳開罐、舀茶、補回茶葉、提壺傾斜注水、蓋壺浸泡及倒茶入杯。水量與灑水即時計算，沙漏可暫停，失手可補水或重泡；滑鼠、觸控及鍵盤皆可操作。
- 茶種、份量、水溫、浸泡與灑水參與計分；泡得不完美仍能繼續故事。遞茶後播放這杯主導茶種的 10 秒製茶影片（八種茶各一支）：林澄的雙手以筆式握法舀茶、銅壺注水時茶葉舒展、手指穿過壺把倒茶並以食指按住壺蓋，最後雙手扶著杯碟推到訪客面前。加了故事配料的杯子另有四支配料影片：蘋果乾或檸檬片落進壺中浮起、海鹽焦糖邊沉邊融、蜂蜜從蜂蜜棒垂進壺裡，奉茶時杯碟上也留著一份。各茶的茶罐、乾茶葉形、舒展後的葉片或花朵、側碟材料、湯色與升起的茶香粒子都不同；杯中茶湯仍依實際泡法著色。可暫停／略過，減少動態時顯示奉茶畫面，再銜接對話。
- 茶席沙漏外環標出最佳提壺時機，浸泡時依茶種飄出桂花、薄荷葉、薰衣草等茶香粒子，並有隨傾斜變化的注水聲。
- 午夜茶席：今日茶單、夜間營業與自由茶席三種玩法；風爐四段火力煮水（蟹眼、魚眼、連珠、鼓浪，滾太久會水老）；花香先綻、醇厚後出、久泡發澀的時間風味與每位客人的最佳提壺時機；八種配料分壺中浸泡與杯中調味；配方、份量、煮水、注水、浸泡、倒茶、茶湯七步完成度；客人口味期望與特別要求、三星評分與下一杯提示、二十款特調茶譜、稱號與每日紀錄、故事訪客回訪當常客，進度與進行中的一杯都存在本機。
- 靜蘭三枚信件碎片、柏言四句辭職信、若音的雙面信、葉暖的雙面食譜、雨航的四片藍色信與海明的紙船信，可用滑鼠或觸控拖曳到信紙，支援吸附、移動與留白；點選及鍵盤操作仍可使用。七章拼信工作區可用手機雙指縮放或按鈕調整至 100%–175%。若音的四音回應可聆聽或查看文字提示；葉暖的爐火、雨航的投遞與郵票、海明的守燈與原句保留會影響結局。
- Dexie 3 個輪替自動檔、10 個手動檔、各已完成章節的首次快照、跨新遊戲保留的收藏。
- 存檔格式與故事版本驗證、序列寫入、防覆寫確認、儲存錯誤提示。
- 鍵盤操作、文字放大、高對比閱讀、對話逐字顯示與四種文字速度、減少動態、手機直向介面。
- 原創書店旋律、窗邊雨聲與室內環境音，以及紙張、茶杯、門鈴音效；首次操作後播放，可分組調整音量或全部靜音。音檔隨 PWA 離線快取。
- PWA manifest、第一夜故事預快取、後續章節與影片按需快取、更新提示及舊版存檔相容。

## Remotion 製片

已建立獨立的 `video/` 製片目錄。遊戲使用八支 `TeaBrew` 製茶影片：720p／30 fps／10 秒，林澄的雙手由程序式 3D 手部模型演出。執行 `npm ci --prefix video` 後，以 `npm run video:studio` 預覽，`npm run video:render:brew -- --tea=all --publish` 輸出、驗證並更新本機八支影片與共用湯色遮罩，`--garnish=all --publish` 更新四支配料影片。舊注水與單杯完成動畫（720p／30 fps／6 秒）及更早的四段原版影片保留作回退。詳細流程見 [製片室文件](video/README.md)。目前主要操作採即時 SVG 茶席，影片不控制拖曳、水量或計分。

## 下一階段

六位訪客、童年林澄與店主已有透明立繪；七章 25 段記憶各有桌機與手機背景，見[章節美術紀錄](docs/CHAPTER_ART.md)。柏言的列車通知、葉暖的蘋果乾、雨航的檸檬與海明的海鹽焦糖均已接入互動。仍需更多人物表情與各場景更完整的演出。製茶影片的雙手是程序式 3D 渲染，不是實拍；影片沒有音軌。各章規劃的 35–60 分鐘目標時長仍需擴充內容並真人閱讀測量。28 種結局已有桌機／手機的結局畫面與收藏定向測試，21 種替代結局也各有一條從該夜開場玩到結局的瀏覽器路線。跨章回應已延伸到多處中段探索，仍待補齊其餘分支。詳細缺口見 [PRD 驗收表](docs/PRD_GAP_AUDIT.md)。GSAP 與 PixiJS 仍未匯入遊戲 runtime；Howler 用於聲音播放。沒有帳號、後端或雲端存檔。

| 位置              | 責任                                  |
| ----------------- | ------------------------------------- |
| `story/`          | 故事唯一來源；生成 JSON 不手改        |
| `src/story/`      | Ink 指令解析與 runtime bridge         |
| `src/stores/`     | 遊戲編排、畫面狀態、閱讀偏好          |
| `src/services/`   | 製茶與拼信純函式判定                  |
| `src/db/`         | IndexedDB schema、原子寫入、存檔驗證  |
| `src/data/`       | 章節、茶方、結局、信片、素材 manifest |
| `src/components/` | 可組合的對話、製茶、拼信與共用 UI     |
| `src/views/`      | 六個頁面與導覽                        |
| `tests/`          | 故事路徑、資料邏輯、桌機／手機 E2E    |

存檔的 `version` 是資料格式，`storyVersion` 是編譯故事相容性契約。改動 Ink 結構時必須評估相容性並提升 storyVersion，新增明確 migration 後才讀入舊版。不可直接刪除不相容存檔。
